用 WiFi 信号就能感知人体，完全不需要摄像头，这事真的成了。

第一个 RuView，把家用路由器的 WiFi 信号变成空间雷达。不用一个摄像头，就能检测人体位置、呼吸频率，连老人跌倒都能发现。今天涨了六百多星，将近七万总星，Rust 写的。

第二个 markitdown，微软出品，今天涨了两千四百星，加速上涨中。把 Word、PDF、Excel 各种文件一键转成 Markdown，相当于给大模型开了个万能文件转换器。

第三个 liteparse，LlamaIndex 用 Rust 写的极速文档解析器。今天九百多星，解析速度碾压同类，开源免费。做 RAG 应用的开发者直接上手。

第四个 VoxCPM，清华 OpenBMB 团队出品。最大亮点是不需要 tokenizer，就能做高质量多语言语音克隆，还能设计全新的声音角色。今天涨了六百多星。

第五个 ECC，将近二十万星。AI 智能体性能优化系统，给 Agent 加上记忆、直觉、安全和研究能力。用 Claude Code 和 Cursor 的开发者已经在用了。
