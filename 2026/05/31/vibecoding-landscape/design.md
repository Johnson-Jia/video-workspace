# VibeCoding大赏 | AI 造视频 — 横屏版

## 基本信息

- **视频方向**: 横屏 1920×1080
- **目标时长**: ~480s (8分钟)
- **场景数**: 11
- **情感内核**: 技术分享 + 开发者自豪感 + 从零到一的创造故事
- **配色方向**: 深空科技 — 深蓝(#0a0e27) / 深紫(#1a0a2e) / 青绿(#00f0ff) / 电光蓝(#4a7cf7) / 琥珀橙(#ff8c00)
- **视觉风格**: 代码美学 + 数据可视化 + 横屏多栏布局
- **BGM 风格**: 科技电子 / 合成器浪潮
- **TTS 音色**: zh-CN-YunjianNeural +25%

## 场景叙事大纲

### s1-hook (25s) — 开场冲击
**核心**: 用震撼数据开场，制造悬念
**信息点**: 8天 / 60次提交 / 2万行代码 / AI自主造视频
**视觉**: 超大数字全屏冲击 + 代码雨矩阵背景 + 计数器动画
**情绪**: 震撼、好奇、冲击

### s2-origin (40s) — 起点
**核心**: 为什么需要 ClipForge — 痛点 + 转折
**信息点**: 短视频制作门槛高 / 知道讲什么但做不成视频 / HyperFrames 转折 / 自动化管线定位
**视觉**: 左右分屏对比（痛点 vs 解决方案）+ 瀑布流管线图
**情绪**: 共鸣、顿悟

### s3-philosophy (45s) — 设计哲学
**核心**: "流程零自由度，内容最大自由度"
**信息点**: LETTER vs SPIRIT 双模式 / Schema 即真相 / 状态即文件 / 委托不重写
**视觉**: 天平/对称构图 — 左侧流程约束(刚性齿轮) vs 右侧创意自由(流体色彩)
**情绪**: 理性、清晰、设计感

### s4-pipeline (50s) — 九阶段管线
**核心**: DAG 编排 + 黄金3秒法则
**信息点**: 9阶段全景 / DAG 并行 / env-check→cleanup 全链路 / 22+门禁 / 32组件 / 黄金3秒
**视觉**: 水平管线流程图 + 并行分支标注 + 数据指标浮动标签
**情绪**: 专业、系统、宏大

### s5-engine (60s) — 四原子约束引擎
**核心**: Intent/Boundary/Gate/Trace — 从事故中学习
**信息点**: 四原子模型详解 / 8个事故→8条规则 / 正向规则优于禁止清单 / 约束注入流程
**视觉**: 四象限布局 + 事故表格卡片翻转 + 引擎架构图
**情绪**: 严谨、工程感、从失败中成长

### s6-rendering (55s) — 三层渲染架构
**核心**: bg/fx/content 三层分离 + 骨架插槽 + 组件库
**信息点**: 三层架构表 / CreativeSlot 数据模型 / 32组件库分类 / GSAP seek 模式
**视觉**: 三层透明叠加示意(左) + 代码骨架(右) + 组件网格展示
**情绪**: 技术深度、优雅、结构美感

### s7-sync (40s) — 音画同步

**情绪**: 精确、技术挑战与解决
