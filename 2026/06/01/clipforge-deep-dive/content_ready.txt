# ClipForge 深度解析 — AI 视频锻造炉的诞生

## 视频模式
单主题深度解析（3-5 分钟长视频，12-15 场景，横屏 1920×1080）

## 主题
从一个开发者的视角，讲述 ClipForge 的诞生故事——为什么做、怎么做的、实现了什么、背后的架构和哲学

## 故事线：从痛点到解决方案

### 故事起点（为什么做）
做一条 1 分钟的短视频，需要：选题调研 → 写文案 → 配音 → 找配乐 → 做画面 → 剪辑渲染 → 做封面 → 写文案标签 → 发布。保守估计 4 小时起步。其中大部分是重复劳动——每次都是相同的流程，只是内容不同。

作为一名开发者，我不喜欢重复劳动。能不能让 AI 驱动每一个环节，把视频制作变成一条自动化流水线？

### 核心设计哲学（怎么想的）
三条铁律贯穿整个设计：
1. **Schema 即真相** — 所有依赖关系、产出定义在一个 YAML schema 文件里，这是唯一真相源。不接受代码里散落的隐式依赖
2. **状态即文件** — 没有 Redis、没有数据库。文件存在 = 阶段完成。中断了？重新运行就自动跳过已完成的阶段
3. **委托不重写** — HTML 渲染委托 HyperFrames，TTS 委托 Edge-TTS，BGM 处理委托 FFmpeg。每个环节用最专业的工具

### 管线架构（怎么做的）
9 个阶段，DAG（有向无环图）编排：

```
内容采集 → 视觉设计 → 旁白生成 → 音频合成（TTS+BGM）
    ↓                                    ↓
素材准备（可选）                    视频渲染（HTML→MP4）
    ↓                                    ↓
    └──────────────→ 平台交付 → 机器评分 → 清理
```

关键设计：DAG 依赖不是阻塞门禁，而是使能者。`requires` 表示"输入就绪"，已完成的 artifact 扫描到文件存在即跳过。这使得管线天然支持断点续跑。

### 规则引擎（怎么控住 AI）
让 AI 自由发挥很容易失控。规则引擎提供四原子约束体系：

| 原子 | 职责 | 类比 |
|------|------|------|
| **Intent** | 定义每个阶段的目标 | 任务书 |
| **Boundary** | 约束 AI 的行为边界 | 围栏 |
| **Gate** | 自动检验产出物 | 质检员 |
| **Trace** | 全程记录执行轨迹 | 行车记录仪 |

执行流程：
1. **注入（inject）**：运行前，将正向规则、经验模式、Guard Red Flags 注入 LLM 的上下文
2. **执行（execute）**：LLM 在约束范围内自由创作
3. **门禁（gate）**：运行后，自动检查文件是否存在、码率是否达标、排版是否合规、BGM 是否合理
4. **轨迹（trace）**：记录每步的结果，用于事后归因

规则分两种：
- **HARD 规则**：门禁不通过 = 阶段失败，必须修复重试
- **SOFT 规则**：警告，由人类决定是否接受

### 视觉系统（怎么做出好看的画面）
每个画面分三层：

| 层 | z-index | 职责 | 示例 |
|----|---------|------|------|
| **bg 背景层** | 1 | 营造氛围和基调 | 渐变光场、噪点纹理、等高线、光束射线 |
| **fx 特效层** | 2 | 创造动感和视觉张力 | 粒子系统、扫描线、光球脉动、数据雨 |
| **content 内容层** | 3 | 传递核心信息 | 文字、数据卡片、代码片段、排名 |

30+ 视觉组件（bg 组件 + fx 组件 + content 组件），每个组件是 HTML+CSS+GSAP 模板。组件匹配不到时，从内容自主推导创建新特效。

所有动画用 GSAP（GreenSock），不用 CSS animation——因为 HyperFrames 通过 seek 驱动时间线，CSS animation 在 seek 时不执行。

### 最重要的设计洞察
**流程零自由度，内容最大自由度。**

管线的每一步——DAG 编排、门禁检验、三层架构、字号底线、安全区 padding——必须严格遵守（LETTER）。但视觉表达、配色方案、动画效果、布局节奏——完全由 AI 从内容推导（SPIRIT）。

这个区分是 ClipForge 最核心的设计理念。它不是限制创造力，而是把创造力释放到该释放的地方。

### 技术实现
- **规则引擎**：Python 解析 YAML 规则文件，支持 GLOBAL/SCENE/SKILL 三级作用域，正则/语义双重检测
- **约束注入**：engine/inject.py 将正向规则（"应该做什么"）和 Guard Red Flags（"常见的错误想法"）注入 LLM 上下文
- **门禁系统**：engine/gate.py 实现 30+ 种自动检查（文件存在、码率、排版、BGM 时长、CSS 可见性等）
- **场景组合**：HTML + CSS + GSAP + 内嵌 `<audio>` 元素（旁白 + BGM 原生混音）
- **语音合成**：Edge-TTS（微软 Azure TTS 免费接口），中文男声 YunjianNeural
- **视频渲染**：HyperFrames 逐帧渲染 HTML 为 MP4，支持 seek 精确控制时间线
- **声明式配置**：每个阶段的约束、门禁、偏好全部在 YAML skill 定义中声明

### 双闭环进化系统
即时闭环（每次制作）：
- 机器评分 → 门禁全量校验 → 输出 score_report.json
- 门禁拦截 = 立即修复重试

延迟闭环（发布后）：
- 播放数据（完播率、5 秒完播率、点击率）+ 人类主观评分
- 对比机器预测 vs 实际表现
- 偏差校准：调整门禁参数、新增/修改规则

已积累 30+ 条规则（R-R-001 到 R-R-020），每一条都来自真实事故复盘。

### 实际成果
- **标准模式**：45-55 秒，6-8 场景，多主题快速盘点
- **深度解析**：45-60 秒，7-8 场景，单主题深入讲解
- **长视频**：3-5 分钟，横屏，深度讲解
- 支持内容分类：GitHub 项目、技术分析、漫画解读等
- 全自动化：cron 定时触发 → SubAgent 执行 → 自动评分 → 自动清理

### 分类系统
每个内容类型有独立配置文件（categories/），覆盖数据获取方式、音色选择、风格偏好、标签列表等。通用 stage 提供默认值，分类配置只声明差异项。

## 选取优先级（12-15 场景）
1. Hook：AI 自制视频的震撼开场（8-10s）
2. 痛点：手动做视频有多痛苦（10-15s）
3. 灵感：开发者的自动化直觉（10-15s）
4. 哲学：三条设计铁律（15-20s）
5. 管线：DAG 9 阶段全景（15-20s）
6. 规则引擎：四原子约束体系（15-20s）
7. 注入→执行→门禁流程（15-20s）
8. 视觉系统：三层架构 + 30 组件（15-20s）
9. 设计洞察：流程零自由度·内容最大自由度（15-20s）
10. 代码实现：技术栈全景（15-20s）
11. 双闭环进化：即时 + 延迟反馈（15-20s）
12. 实际成果展示（10-15s）
13. CTA：开源邀请（8-10s）
