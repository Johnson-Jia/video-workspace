# RuView 项目深度解析 — 内容摘要

## 视频主题
揭露 GitHub 开源项目 RuView (ruvnet/RuView) 的虚假宣传，帮助开发者避免被骗。

## 核心信息点（按重要性排序）

### 1. 项目定性
- 一句话："画了法拉利外壳的电动自行车"
- 工程量巨大（38 crate、148 ADR、50+ C 文件、23 CI workflow），但核心能力严重夸大

### 2. 真实能力 vs 虚假宣传对照表
| 功能 | 真实性 |
|------|--------|
| WiFi CSI 数据采集 | 真实（50+ C 文件 ESP-IDF 固件）|
| 信号处理 FFT/滤波 | 真实且专业（Rust + Python 双实现）|
| 存在/运动检测 | 真实且可行 |
| 呼吸频率检测 | 代码真实，精度存疑 |
| DensePose 姿态估计 | 架构存在，演示用启发式公式而非神经网络 |
| 54K fps 推理速度 | 无证据，零基准测试 |
| 94.2% 姿态准确率 | Python v1 用 np.random.rand() 造假 |
| 灾难幸存者检测 | 无证据，零独立验证 |

### 3. 造假证据（关键代码证据）
- Python v1: `csi_extractor.py` 文本模式用 `np.random.rand()` 生成假 CSI 数据
- Rust v2: `derive_single_person_pose()` 用硬编码偏移量+几何公式生成姿态，非神经网络推理
- 假 HMAC: 用 XOR 折叠替代 HMAC-SHA256，硬编码测试密钥
- 性能测试: 用 `asyncio.sleep()` 模拟，无真实计算测量

### 4. 社区验证
- Fork 审计 (deletexiumu/wifi-densepose): 确认 Python v1 为骗局
- 独立质量工程审计: 安全评级 F，7 个 CRITICAL 级漏洞
- B 站评测: 演示效果有限，评价为"夸张"

### 5. 技术可行性分析
- WiFi CSI 感知是真实研究领域（CMU、MIT、Stanford 有论文）
- 存在检测：成熟可靠
- 姿态估计：极早期，实验室外几乎不可行
- 需要大规模配对数据集、严格环境控制、精确设备校准

### 6. 安全问题
- 7 个 CRITICAL 级安全漏洞
- 7,312 行单文件 main.rs，圈复杂度 CC=65
- 默认禁用认证（`ENABLE_AUTHENTICATION=false`）

### 7. 给不同受众的建议
- 研究者：信号处理代码可参考，不要依赖姿态估计
- 开发者：Rust 架构值得学习，存在检测可用
- 投资者/决策者：生命安全场景绝对不可用
- 普通用户：不要期望"无摄像头精确姿态估计"
