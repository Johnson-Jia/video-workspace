# Design — GitHub星探 频道自述

## 视频模式
频道自述/人设视频（非项目讲解）

## 主题
GitHub星探 频道初心 — 开源精神 × 星火燎原

## 情绪基调
沉思 → 共鸣 → 振奋 → 感召

## 情绪弧线
| 阶段 | 场景 | 情绪 |
|------|------|------|
| 钩子 | hook | 温暖、好奇（向观众提问） |
| 证明 | proof | 敬佩、认同（开源案例） |
| 信仰 | faith | 深沉、肃穆（精神内核） |
| 假设 | whatif | 期待、遐想（超越代码） |
| 裂变 | multiply | 加速、振奋（乘法效应） |
| 高潮 | spark | 壮阔、激昂（星火燎原） |
| 归属 | you | 温暖、拥抱（你就是星火） |
| 行动 | cta | 感召、同行（一起走） |

## 视觉风格
- **沉浸模式**: 情感叙事（暗色宇宙 → 渐亮星火）
- **配色**: 深邃宇宙底色(#05080F) + 暖金/琥珀星火(#FFB800) + 辅助暖白(#FFF5E6)
- **核心意象**: 星空→孤星闪烁→星火汇聚→燎原之光
- **风格原则**: 从极暗极静渐进到温暖明亮，用光的变化映射情感升温

## 配乐方向
- **氛围**: 从沉思钢琴渐进到壮阔管弦
- **关键词**: cinematic piano, building orchestral, hopeful epic
- **节奏**: 前半克制沉思，后半逐渐推向高潮，spark 场景达到峰值

## 场景规划（8 场景，~90s）

| 场景 | 类型 | 预估时长 | 内容焦点 |
|------|------|---------|---------|
| s1-hook | hook | 12s | "什么样的人会关注？" + 开源信仰者 |
| s2-proof | build | 10s | Linus/Linux + PR 贡献 |
| s3-faith | reveal | 7s | 开源是一种信仰 |
| s4-whatif | build | 7s | 如果不止于代码？ |
| s5-multiply | accelerate | 8s | 1→10→100 乘法效应 |
| s6-spark | climax | 18s | 星火燎原（核心高潮） |
| s7-you | landing | 5s | 你就是星火 |
| s8-cta | cta | 8s | 一起燎原 + 感谢 |

## 素材需求
- 星空/宇宙背景（CSS 渐变+粒子）
- 星火/光点动画（CSS glow + GSAP）
- 文字排版（大字冲击 + 渐变文字）
- 纯 CSS/HTML 实现，无需外部图片
