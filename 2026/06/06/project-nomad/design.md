# Design — Project N.O.M.A.D. 深度讲解

## 视频模式
单项目深度解析（扩展至 ~3 分钟）

## 内容来源
workspace/sources/GitHub项目分析报告/project-nomad-video-report.md + 项目源码

## 主题
Project N.O.M.A.D. — 完全免费的开源离线知识服务器

## 情绪基调
好奇 → 震撼 → 理解 → 共鸣 → 行动

## 情绪弧线
| 阶段 | 场景 | 情绪 |
|------|------|------|
| 钩子 | hook | 紧迫、好奇（反直觉冲击） |
| 揭示 | what | 震撼、惊喜 |
| 深入 | philosophy | 沉思、理解 |
| 拆解 | architecture | 理性、信服 |
| 亮点 | features-ai | 惊艳、兴奋 |
| 补充 | features-tools | 实用、踏实 |
| 客观 | limitations | 冷静、诚实 |
| 应用 | usecases | 共鸣、联想 |
| 行动 | cta | 启发、期待 |

## 视觉风格
- **沉浸模式**: hidden-gem（渐进揭示 + 温暖光效）
- **配色**: 深色科技底色(#0A0E17) + 琥珀色/暖金强调色(#FFB800) + 辅助青色(#00D4FF)
- **风格原则**: "末日知识库"但不末日感——用暖金色传递"知识的温度"，深色底保持科技感

## 配乐方向
- **氛围**: 电子氛围，略带神秘感，渐进能量
- **关键词**: ambient electronic, mysterious building, cinematic atmosphere
- **节奏**: 前半段克制（好奇→理解），后半段逐渐增强（共鸣→行动）
