你的 AI 助手只能查网页，搜不了社交动态、读不了内容平台、更拿不到视频弹幕。今天介绍一个项目，十多个主流平台一次性打通。
Agent Reach，开源脚手架工具。它不做框架，不做 API 封装，只做一件事：把 AI Agent 接入互联网所需的工具，装好、配好、诊断好。Python 3.10 以上，MIT 协议，253 次提交，15 位贡献者。
它的核心设计哲学叫脚手架模式。区别在哪？框架会把你包起来，所有调用都经过它。脚手架不同，帮你搭好梯子就退出。装完之后，Agent 直接调用 yt-dlp、gh 这些原生工具，不经过任何中间层。好处是零运行时依赖，出问题直接找上游工具。坏处是每个工具都得单独装。
架构分三层。最上面是 SKILL.md 路由，告诉 Agent 遇到什么需求用什么命令。中间是 Channel 插件层，每个平台一个独立模块，检测上游工具状态。最底下是上游工具层。平台按难度分三个等级：Tier 0 装好即用，包括网页搜索、油管、GitHub 和技术社区；Tier 1 需要登录凭据，覆盖社交平台、视频网站、内容社区和财经论坛；Tier 2 配置复杂，主要是短视频平台和海外职场社交。
一共覆盖十多个平台。网页搜索用 Jina Reader，免费无需 Key。视频字幕用 yt-dlp 提取，这个工具 15 万星。代码仓库用官方 CLI。中文生态很完整：视频网站、社交平台、短视频、资讯社区、财经论坛全有。还有 RSS 订阅、播客转录，以及 Exa 全网语义搜索，免费无需 API Key。所有上游工具免费，用户唯一可能的花费是服务器代理，一个月一美元。
凭据管理是项目的一大亮点。支持从 Chrome、Firefox、Edge 等主流浏览器自动提取，一次覆盖社交平台和内容社区的所有登录状态。安全方面做了三件事：配置文件权限设为 600 只有你能读写，日志输出自动脱敏不泄露凭据，还有 safe 模式和 dry-run 模式，生产环境可以先预览再执行。
安装只需一条命令：agent-reach install --env=auto。它会自动检测环境，安装依赖，然后按需装各平台上游工具。本地模式还会自动从浏览器提取凭据。安装完运行 doctor，一键诊断所有渠道的状态。整个过程不超过五分钟。
适合什么场景？第一，给 AI Agent 加互联网能力，这是核心定位。第二，社交媒体监控，多个平台一站搜完。第三，技术信息聚合，GitHub Issue、技术社区一键抓取。第四，金融市场信息，财经社区实时行情和热帖。第五，内容创作辅助，视频字幕提取、播客转文字。
但有几个风险必须说清楚。第一，上游工具多基于逆向工程，平台反爬升级随时可能失效。第二，登录凭据会过期，部分平台的需要定期更新。第三，使用非官方接口有封号风险，建议用小号。第四，Windows 兼容性有限，部分安装命令只支持 Linux。第五，不适合大规模采集和商业用途。
总结一下。推荐给个人开发者、研究人员、AI Agent 用户。代码质量不错，文档中英日韩四语，253 次提交说明迭代活跃。对个人用户来说，这是一个零成本打通互联网信息的好工具。但如果你需要商业级稳定性，或者大规模数据采集，不适合。项目名叫 Agent Reach，作者 Neo Reid，MIT 协议。
