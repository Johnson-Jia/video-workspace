6月13日 GitHub 杀入几个猛项目，Apple 官方开源了个容器工具，单日冲上三千五百星
apple/container，苹果用 Swift 写的轻量容器工具，专为自家芯片优化。Mac 开发者终于不用装 Docker 桌面版了。三万五千星，今日最高涨星。
superpowers，把开发方法论打包成 Agent 能直接调用的技能包。二十二万星，技能框架确实是今年最热的风口。
openmed，开源的本地推理框架，模型在设备端跑，不依赖云端。支持文本理解和信息抽取，三千二百星，涨星还在加速。
PowerToys，微软官方的 Windows 效率工具合集，窗口管理、批量重命名、颜色拾取一应俱全。十三万星，连微软都觉得 Windows 自带功能不够用。
mattermost，十一年老项目突然加速，单日涨星从二十六飙升到三百九十一，十五倍。自托管协作，数据完全自主。
LMCache，专攻大模型推理的 KV 缓存层，把推理速度拉满。八千六百星，支持主流推理框架。
今天六个项目，从容器到效率工具到推理加速，开源正在把专业能力送到每个人手上。关注我，下期见。
