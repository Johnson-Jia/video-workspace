- **[HARD]** 所有表述使用限定性语言，如'可能'、'通常'、'值得关注' （自检: 输出包含'必装'、'必备'、'神器'、'最强'、'最好'等词视为违规）
- **[HARD]** 只展示项目名称/产品名称，链接放评论区 （自检: 画面或旁白包含 github.com/xxx 或 https://xxx.com 形式的 URL）
- **[HARD]** 只描述能力，不说获取路径：说'能做什么'，不说'去哪下载/怎么安装' （自检: 旁白或评论区出现'下载安装包'、'双击安装'、'打开浏览器就能用'等表述）
- **[HARD]** 使用技术类别描述（如'大语言模型'、'AI 助手'），不点品牌名 （自检: 出现'GPT'、'DeepSeek'、'通义千问'等具体品牌名）
- **[HARD]** 画面文字全部使用中文，仅项目名和技术缩写保留英文 （自检: 画面包含 TRENDING TODAY、TOP 3、FOLLOW 等非中文文字）
- **[HARD · 机器拦截: check_no_real_person_name]** 使用泛化表述（如'国内高校团队'、'研究团队'），不提具体姓名 （自检: 旁白、画面文字或发布文案中出现真实人名（如教授/学者/企业家姓名），触发平台个人隐私保护审核 → 不适宜公开）
- **[HARD · 机器拦截: check_no_school_name]** 使用'国内高校'、'国内研究机构'等泛化表述 （自检: 出现'中科大'、'清华'、'北大'、'浙大'等具体学校名或'XX实验室'等机构名，触发平台隐私保护审核）
- **[HARD · 机器拦截: check_no_competitor_attack]** 只正面描述自身项目特点，不提竞品名称和缺点。如需对比，用'同类方案侧重 XX'等中性表述 （自检: 旁白或画面出现竞品名称+负面描述（如'LiveTalking缺XX'、'XX不如'），触发平台'贬低同行/恶意竞争'审核）
- **[HARD]** 使用限定性表述（'表现不错'、'值得关注'、'颇有亮点'） （自检: '别人没做的事'、'远超预期'、'都方便'等绝对化/夸大用语，触发平台'虚假宣传'审核）
- **[HARD · 机器拦截: check_no_search_cTA]** 只列项目名和 owner/repo 路径（如 apple/container），不写'去 GitHub 搜索''搜名字就能' （自检: '去GitHub搜'、'GitHub搜索:'、'搜项目名'、'感兴趣...搜'等表述触发平台'导流'判定限流）
- **[HARD · 机器拦截: check_douyin_platforms_complete]** douyin.md 全文零链接，项目只以 owner/repo 文本路径形式出现在评论区自评段 （自检: douyin.md 出现 https://... 形式 URL，平台判定导流并限流）
- **[HARD]** 评论区只列项目名称 + '搜名字就能找到'，不放完整链接 （自检: douyin.md 中包含 github.com 或 https:// 形式的 URL）
- **[HARD · 机器拦截: check_cover_layers_present]** 封面必须包含：日期 + 场景标签 + 胶囊徽章 + 双色主标题 （自检: cover.html 缺少日期/标签/主标题之一）
- **[HARD]** 封面所有可见文字使用中文，仅保留项目名和技术缩写英文 （自检: 封面 HTML 中包含 TRENDING、TOP、FOLLOW 等英文装饰文字）
