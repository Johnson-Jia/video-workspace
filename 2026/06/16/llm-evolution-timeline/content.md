## 关键信息点（按 7 阶段时间线，含置信度）

### 第一阶段：技术奠基期（2017）

1. **2017-06 Google《Attention Is All You Need》—— Transformer 架构**【证】**T0**
   - arXiv:1706.03762（Vaswani 等，NeurIPS 2017）
   - 纯自注意力 + 编码器-解码器，取代 RNN/LSTM，实现序列并行训练
   - **全表唯一 T0 基石**：所有现代 LLM 与多模态大模型的唯一技术原点，无 Transformer 则无当下大模型产业

### 第二阶段：预训练范式确立期（2018-2019）

2. **2018-06 OpenAI GPT-1（约 1.17 亿参数）**【证】**T2**
   - Decoder-only 单向预训练 + 下游微调，确立**生成式路线**
3. **2018-10 Google BERT（1.1 亿 / 3.4 亿参数）**【证】**T2**
   - Encoder-only 双向掩码语言模型，NLU 榜单碾压传统模型
   - 与 GPT 形成 **"生成（GPT）+ 理解（BERT）"双路线**，沿用至今
4. **2019-02 OpenAI GPT-2（15 亿参数，零样本）**【证】**T2**
   - 取消下游微调，展现零样本泛化；建立"大数据+大参数→强通用能力"工程认知

### 第三阶段：千亿规模跃迁 + 产业落地（2020-2021）

5. **2020-05 OpenAI GPT-3（1750 亿参数）**【证】**T1**
   - 首个千亿级通用模型，45TB 文本预训练
   - **产业元年级**：验证规模定律（Scaling Law），完成"实验室模型→产业工具"跨越，触发全球军备竞赛
6. **2020 Google T5 / 2021 Google FLAN**【证】**T4**
   - 统一 NLP 为"文本到文本"+ 大规模指令微调，奠定"预训练+指令微调+对齐"流水线
7. **2021-07 华为盘古大模型首次官方发布**【参】**T3**
   - 超千亿参数中文大模型，基于昇腾 + MindSpore
   - 国产"芯片+框架+模型"全栈能力早期证明（豆包版"2000亿/1.1TB"数字未获 primary 证实，已更正为稳妥口径）
8. **2021-10 Microsoft × GitHub Copilot（Codex）**【证】**T2**
   - 首个现象级垂直 AI 工具，实时代码补全；完成大模型**生产力工具商业化闭环**

### 第四阶段：对话革命 + RLHF 对齐成熟（2022）

9. **2022-01 OpenAI InstructGPT（GPT-3.5 雏形）**【证】**T2**
   - 落地 SFT + RLHF 完整对齐体系，RLHF 成对话模型标配，为 ChatGPT 奠基
10. **2022 华为盘古气象大模型（Nature 正刊）**【证】**T3**
    - 三维神经网络中期全球天气预报，传统数值预报（数小时级）压缩至秒级
    - 开创 **AI for Science 大模型赛道**，颠覆传统数值模拟范式
11. **2022-11-30 OpenAI ChatGPT（GPT-3.5-turbo）**【证】**T1**
    - RLHF 优化多轮对话，免费向全民开放
    - **全民 AI 时代开启**：2 个月用户破亿（史上普及最快的消费级科技产品之一），倒逼全球科技公司战略转向，开启"闭源商用 vs 开源普惠"双格局

### 第五阶段：开源爆发 + 多模态登顶 + 国产崛起（2023）

12. **2023-02 Meta LLaMA（7B-65B）**【证】**T1**
    - 高质量开源基础模型，社区广泛二次开发（非"权重泄露"，实为研究预览权重公开）
    - **技术民主化革命**：打破闭源垄断，催生 Alpaca/Vicuna 等衍生，开源生态成型
13. **2023-03 OpenAI GPT-4（多模态）**【证】**T2**
    - 图文多模态输入、长上下文、顶级推理，多项专业考试超越人类专家水平
    - 确立高端大模型"多模态+强推理"标准，进入"GPT-4 对标时代"
14. **2023-03 华为 PanGu-Σ（万亿级，1085B 参数）**【证】**T3**
    - 1085B 参数、329B tokens、40+ 语言，512 颗昇腾 910 训练 100+ 天，RRE 架构
    - （豆包版"2023-07 盘古3.0"时间错误，实际 2023-03）
15. **2023 年中 中国大模型集体爆发（"百模大战"元年）**【证/参】**T2**
    - 百度文心一言（2023-03-16）、阿里通义千问（2023-04-11 峰会对发布）、讯飞星火、字节豆包
    - 开启中国大模型元年，形成中美双极竞争格局

### 第六阶段：推理范式革命 + 全模态 + MoE 工程化（2024）

16. **2024-02 Google Gemini 1.5（100 万 token 上下文）**【证】**T2**
    - MoE 架构，100 万 token 上下文窗口——上下文长度重大跃迁
17. **2024-05 DeepSeek-V2 开源（236B/21B MoE）**【证】**T2**
    - 引入 MLA（多头潜在注意力）+ DeepSeekMoE，性能对标 GPT-4 Turbo，奠定 DeepSeek 的 MoE 路线
18. **2024-05 OpenAI GPT-4o（全模态实时交互）**【证】**T2**
    - 文本/图像/音频超低延迟实时交互；多模态从"高端配置"变"基础能力"
19. **2024-09-12 OpenAI o1 —— 首个"推理模型"**【证】**T2**
    - 强化长思维链（chain-of-thought）推理，模拟"系统 2"深度思考
    - 推动大模型从"内容生成"进阶到复杂逻辑推理/科研创新，开启"推理模型"范式
20. **2024-12-26 DeepSeek-V3 开源（671B / 37B 激活 MoE）**【证】**T1**
    - 14.8T tokens 预训练，仅需 2.788M H800 GPU 小时；首创无辅助损失负载均衡 + 多 token 预测（MTP）
    - 以极低算力达闭源前沿水平，**重新定义大模型训练成本预期**，引爆后续 R1 与"开源周"

### 第七阶段：推理深化 + 开源重塑 + 国产突围（2025-2026.06）

21. **2025-01-20 DeepSeek-R1 开源（671B/37B MoE，MIT 协议）**【证】**T2**
    - R1-Zero 首次公开验证"纯 RL（GRPO，无 SFT）即可激发推理能力"；性能对标 OpenAI o1
    - **开源推理模型分水岭**：证明顶级推理能力可低成本复制，重塑全球"算力壁垒"认知
    - 【疑】"训练成本仅同类 1/20""英伟达单日暴跌 21.6%"为二手/营销表述，论文与财报未直接证实，引用需谨慎
22. **2025-02 DeepSeek"开源周"（基础设施全开源）**【参】**T2**
    - 5 天连续开源 FlashMLA / DeepEP / DeepGEMM / DualPipe 等，训练/推理底层基础设施全面开源，震动英伟达 CUDA 生态话语权
23. **2025-03-25 Google Gemini 2.5 Pro 登顶 LMArena**【证】**T4**
24. **2025-04-10 华为 Pangu Ultra（135B dense，8192 昇腾 NPU）**【证】**T3**
    - dense 非 MoE，提出"depth-scaled sandwich normalization"消除 loss spike；**模型不开源**，仅限商业客户
25. **2025-04-29 阿里 Qwen3 开源（0.6B-235B，8 款，Apache 2.0）**【证】**T2**
    - 国内首个支持"思考/非思考"模式切换的混合推理模型，支持 119 种语言
26. **2025-05-22 Anthropic Claude 4（Opus 4 / Sonnet 4）**【证】**T2**
    - hybrid 模型，SWE-bench Verified 72.5%+；可连续自主工作数小时，确立 AI 编程 Agent 性能前沿
27. **2025-06-20 华为盘古 5.5（HDC 2025，718B MoE）**【证】**T3**
    - NLP 深度思考 718B MoE（256 专家）+ 盘古世界模型（生成数字物理空间训练智驾与具身机器人）
28. **2025-06-30 华为 openPangu 首次开源（openPangu 1.0）**【证】**T3**
    - 开源 7B openPangu + 72B openPangu Pro MoE，推理针对昇腾优化
    - **华为首次正式进入全球开源大模型主赛道**（豆包版完全遗漏的关键节点，是 openPangu 2.0 的直接前序）
29. **2025-08-07 OpenAI GPT-5（统一系统 + 路由）**【证】**T2**
    - 自动实时路由"快速模型 / 深度推理"，替代 GPT-4o、o3、o4-mini 等；从"多模型矩阵"收敛为"单系统智能路由"
30. **2025-11-18 Google Gemini 3 Pro / 3 Deep Think**【证】**T4**
    - 促使 OpenAI 加速 2025-12-11 推出 GPT-5.2 应战，双巨头节奏对抗
31. **2026-01-12 Apple Siri 接入 Gemini**【参】**T4**
    - 标志性跨厂集成
32. **2026-02 阿里 Qwen3.5 开源**【参】**T4**
33. **★ 2026-06-12 华为 openPangu 2.0 开源（HDC 2026）**【参】**T3 / 高潮锚点**
    - **Pro 版 505B 总参 / 18B 激活**；**Flash 版 92B 总参 / 6B 激活**；均支持 **512K 上下文**
    - 计划 6-30 起陆续开源 7 大组件（含新增预训练代码、后训练代码、训练算子）
    - 深度适配昇腾与鸿蒙 Agent；与 DeepSeek 形成"双国产顶级开源"格局
    - 【疑】"单卡吞吐率达其他主流开源 2 倍"为厂商自述，无第三方基准，谨慎引用
