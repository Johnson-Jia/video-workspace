## B站

tmux深度解析：2007年的终端复用器，凭什么让会话永不掉线？client-server架构全拆解

这期把 tmux 的架构讲透。
核心是 client-server 自孵化：一个二进制同时当客户端和服务器。
会话跑在 server 上，和终端解耦，SSH 断了进程还在。
渲染分 grid、screen、tty 三层，事件循环靠 libevent。
对象模型是 session → window → pane → pty，红黑树加队列管。
它也适合 Claude Code 这类长任务命令行场景，社区里不少人拿 tmux 保持会话——不过需要额外配置，SSH 下可能闪烁，官方主推的是 Remote Control 那套。
一个 2007 年的 C 项目，到现在还在维护，3.7 版本，ISC 许可。
做后端和运维的，这套机制值得收藏细看。
