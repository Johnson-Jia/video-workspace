| 这个效果用 CSS animation 更简单 | HyperFrames seek 不执行 CSS animation，所有入场必须用 GSAP | 试图使用 CSS animation 做入场 |
| 三层架构太麻烦，直接写内容就行 | 三层是正确结构，扁平化会导致渲染异常和视觉分层混乱 | 试图省略三层架构 |
