三十多个 Windows 缺的功能，微软自己做，还免费。
它叫 PowerToys，微软官方维护的 Windows 效率工具全家桶。说白了，就是把三十多个本来 Windows 没有、但你天天用得着的小工具，统一打包进一个框架。它们共用一套设置面板、一个托盘图标，一个入口管住所有。它不是要替代 Windows，而是补上 Windows 该有、却一直没做的那些效率功能。
这不是某个个人开发者做着玩的小项目。它是微软官方仓库，九千三百多次提交，MIT 开源协议，到今天还在活跃维护。背后有完整的安全响应流程，有公开透明的隐私文档，连遥测数据都是默认关闭、事件全部写进源码里供你审查。
它的核心架构，一句话能说透：一个调度核心，加上一堆各干各的、却长得一模一样的插件。那个调度核心叫 Runner，就是主进程。它干的活很关键，加载所有工具、守着系统托盘、注册全局快捷键。还有一件，就是把设置面板和各个工具之间，用命名管道桥接起来，让它们能互相通信。
每个工具，都是一个插件，叫 Module。想被 Runner 接受，必须实现一套统一接口：报上自己的名字、注册快捷键、管好各自的配置、还得能被启用和禁用。这套设计的好处非常直接，想新增一个工具，只要写一个实现接口的新插件，核心代码一行都不用改，设置面板里就会自动冒出一个新条目。这就是它能从几个工具长到三十多个，还不乱的原因。
这些工具接入 Windows 的方式，分四种。有的是纯逻辑，整个工具就住在接口里，没有独立程序；有的是你按下快捷键，弹出一个独立小窗口；有的是直接变成资源管理器里的右键菜单项；还有的，是悄悄改注册表，帮你加上文件预览功能。四种姿势，各管一摊。
更有意思的是，它不是从零开始造轮子。取色器，来自社区开发者的开源项目；快速启动器，继承自一个知名的开源启动器，连插件架构都原样保留，第三方还能自己写扩展。而像窗口布局、键盘管理这些核心模块，是微软亲手写的。官方自研打底，再收编社区精华，这就是它的混合策略。
旗舰工具，先说最重磅的 FancyZones，一个窗口分区布局引擎。Windows 自带的分屏太简陋，左右对半、四象限，基本就这点花样。FancyZones 让你自己画格子，三列不等宽、左边一大块右边俩小块，随你怎么定。拖动窗口的时候，它会自动吸附进格子。它是整个代码库里最复杂、最受重视的模块，专门配了模糊测试和完整的界面测试，是当核心产品在打磨的。
第二个，PowerToys Run，快速启动器。快捷键一按就弹出来，你输入什么它就搜什么，应用、文件都能找，顺手还能当计算器、做单位换算。因为它继承了开源启动器的插件架构，功能几乎可以无限扩展。第三个，Mouse Without Borders，无界鼠标，一套键盘鼠标，控制好几台电脑，跨机器复制粘贴、直接拖文件。多电脑办公的人，用上基本就回不去了，前提是这几台机器得联网。
第四个，Advanced Paste，AI 增强粘贴。剪贴板里的内容，它能智能转换格式、做总结、做翻译。它接的是外部的 AI 服务，得你自己配密钥，而且内容会上云，敏感信息得留意。除了这四个旗舰，还有键盘重映射、批量改名、图片缩放、屏幕取色、OCR 识字、屏幕测距、防休眠，三十多个工具，你能想到的效率小功能，它基本都备着。
普通人完全用得上，不用怕门槛高。官方渠道装好之后，按需开三四个就够用，窗口分区、快速启动、取色、批量改名，这四个就能覆盖大部分日常价值。多电脑办公的，再加个无界鼠标。它不要求你全开三十多个，挑你顺手的那几个就行。
但有一个硬限制，必须说清楚，它只支持 Windows，苹果系统和 Linux 都用不了，这是它的根本边界。微软把 Windows 缺的那些效率功能，自己打包补上了，还免费开放。这三十多个工具里，你最想先试哪个？项目叫 PowerToys，评论区有路径。
