# content.md — E01 钩子段（数据飞升冲击）

## 段落定位

E01 第 2 段（开场段后），时长 ~25s。纯钩子段——用三个数据冲击开场，不解释方法论、不展开背景、不介绍教程结构。收尾抛「怎么做到的」悬念，承接介绍段（讲方法论是什么）。

## 核心数据（来自教程仓库 hero）

80+ 人研发团队、3 个月转型、206 个仓库同比统计，三个核心数据：

| 数据 | 数值 | 语义 | 配色 |
|------|------|------|------|
| 人均代码产出 | **+104%** | 翻倍级提升 | 金 #FBBF24 |
| AI 代码占比 | **76.6%** | AI 写了 3/4 代码 | 蓝 #3B82F6 |
| Bug 下降 | **-16.4 个百分点** | 质量同步提升 | 绿 #10B981 |

## 严谨口径（合规底线）

- **数据来源**：教程仓库 hero 区真实团队统计（80+ 人研发团队、千万级用户平台实战验证）
- **统计口径**：3 个月转型前后对比，206 个仓库同比统计
- **相关性非因果**：明确标注「不能 100% 归功 AI」— 转型是系统工程，AI 是关键变量之一，非唯一原因
- **不夸大**：用「三个数据同时飞升」「值得看看怎么做到的」，禁用「最强」「第一」「绝对」「必装」「神器」

## 钩子叙事（两段式）

1. **数据飞升冲击**（~17s）：三个数据卡同屏，按 narration 锚点依次 reveal + count-up 动画（+104% 从 0 滚到 104 / 76.6% 从 0 滚到 76.6 / -16.4pp 从 0 滚到 -16.4），三色对应三数据，冲击累积。底部灰色注释行同屏：「80+ 人团队 · 3 个月 · 206 仓库同比 · 相关性非因果」
2. **悬念收尾**（~8s）：三数据卡保持同屏，hero 区切换为「怎么做到的？」大字（主色蓝），承接介绍段（讲方法论是什么）

## 合规要点

- 数据相关性非因果（画面 + 旁白均不归功 AI 100%）
- 禁绝对化用语（最强/必装/神器/第一/绝对）
- 无 URL / 搜索引导
- 前 3 秒纯数据冲击（+104% 大字），不展开背景
- 教程横屏 reveal 范式（§6.16），一屏多区域 + reveal，不是竖屏 phase 切换
