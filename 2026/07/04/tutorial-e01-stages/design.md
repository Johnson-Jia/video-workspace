## style

清爽专业科技风。教程类要**干净、可读 + 高信息密度**（一屏多区域：阶段名 + 要点 + 产出物 + 数据同屏），不要花哨动画抢注意力。7 阶段全景图场景要一眼看清「总纲 + 6 实施」结构。

## color_direction

深蓝底 + 主色蓝 + 强调色（按内容语义分配，阶段4 闭环用金色高亮「核心」）：

| 用途 | 色值 | 角色 |
|------|------|------|
| 背景 | `#0F172A` | 深蓝主底（沉稳专业） |
| 主色 | `#1E3A8A` / `#3B82F6` | 蓝色主调（阶段名/阶段条/数据卡边框） |
| 蓝白 | `#E0E7FF` | 浅蓝白（正文文字/要点说明） |
| 数据强调 | `#FBBF24` | 金（+50% / 100% 覆盖 / 3-6 月回本 / 「核心」标签 / 「数据说话」高亮） |
| 阶段4 核心高亮 | `#FBBF24`（金）| 阶段4 闭环试点是核心阶段 — 阶段条用金色边框 + 「核心」金色胶囊标签，区别其他蓝色阶段 |
| 可跳过标记 | `#94A3B8`（灰）| 阶段3 基础设施标「小团队可跳过」灰色胶囊（区别必做蓝色阶段） |
| 对比强调 | `#10B981` | 绿（「是」一栏 — 可落地、有 demo、有数据） |
| 对比警示 | `#EF4444` | 红（「不是」一栏 — 玄学、各搞各的、过度工程） |
| 中性 | `#94A3B8` | 灰（次要文字 / 注释 / 「相关性非因果」） |

> 强色控制：金色仅数据高亮 + 阶段4 核心标记；绿仅「是」栏；红仅「不是」栏；灰仅可跳过标记。一屏多区域靠色块区分语义，不靠强切换。

## bg 组件池（≥3 种相邻不同）

- **clean_slate** — 干净深蓝底（用于标题区 hero 呼吸 + 7 阶段全景图，让多区域不互相干扰）
- **scan_grid** — 细网格扫描线（用于阶段要点列表/数据卡/SDD 三产物，科技感衬底不抢文字）
- **gradient_mesh** — 蓝色径向渐变（用于金句区/阶段4 核心高亮/收尾承接，柔和过渡）

> 教程类 bg 定位：**低调衬底，不抢多区域文字**。不用粒子/光晕过载（§6.16 教程横屏禁忌）。

## typography

- 中文标题（hero）：思源黑 / Inter 粗体，96-120px（横屏多区域，比竖屏 hero 小一档）
- 阶段名：思源黑 Bold，64-80px（带阶段编号胶囊「阶段 N」）
- 区域标题：思源黑 Bold，48-56px
- 中文正文/要点：思源黑 Medium，32-40px（横屏可读底线，多区域密度需控字号）
- 数字：等宽数字 / JetBrains Mono Bold，金色高亮 120-160px
- 注释/相关性说明：思源黑 Regular，22-26px，灰色
- 字间距：标题 0.02em，正文 0.01em

## motion

教程横屏 reveal 动画（§6.16 — data-reveal 时间点淡入，克制）：

- 标题区：场景开始即 fade-in（data-reveal="0"）+ 下划线 width 0→100%（600ms）
- 7 阶段全景条：7 个阶段卡横向 stagger 250ms 依次亮起（总纲→战略→赋能→基建→试点→推广→沉淀），阶段4 亮起时金色「核心」胶囊同步弹出，阶段3 亮起时灰色「可跳过」胶囊同步弹出
- 阶段要点列表：左栏阶段名 fade-in + 右栏要点 stagger 200ms 依次淡入（每条间隔与 narration 句子锚点对齐）
- 老板三问区：三问三卡横向 stagger 300ms fade-in，每卡金色问号图标微弹
- SDD 三产物区：spec/plan/tasks 三卡 stagger 250ms fade-in，「左移」箭头从「改代码」（红）滑向「改 Markdown」（绿），800ms
- 数据卡：金色数字从 0 滚动到目标值（500ms，ease-out）+ 「相关性非因果」注释同步淡入
- 金句区：金句条 fade-in + width 0→100%（800ms），长停留
- **区域 reveal 后保持**（不隐藏），同屏累积丰富（区别竖屏 phase 切换换屏）
- **禁**：粒子、过强光晕、闪烁、3D 翻转、3 秒强切换（§6.16 教程横屏最大误区）

## layout_principles

- 横屏 1920×1080 安全区：padding 80px（左右）/ 60px（上下）
- 一屏多区域 grid：标题区顶部（横跨）+ 中部主内容区（grid 2-3 列）+ 底部金句/承接条
- 7 阶段全景条：横向 7 等分排列，每卡 240px 宽，间距 20px，总宽约 1880px 横跨；阶段编号胶囊顶部 + 阶段名中部 + 产出物底部
- 逐阶段场景：左栏阶段名（宽 480px，阶段编号大胶囊 + 阶段名大字）+ 右栏要点列表（宽 1280px，3-4 条要点卡纵向堆叠）
- 老板三问区：三卡横向（每卡 580px，间距 30px），问号图标 + 问题 + 答案三行
- 数据卡：宽 600-800px 居中或右栏，数字 120px+ 配注释小字
- 文字层级：标题 > 阶段名 > 数字 > 区域标题 > 正文 > 注释（6 级清晰，多区域不打架）
- reveal 节奏：每场景 4-5 个区域 reveal，间隔 3-4s（与 narration 句子锚点对齐）
