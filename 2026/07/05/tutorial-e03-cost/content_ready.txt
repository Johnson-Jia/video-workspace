【E03 段2 · 预算 4 块成本——工具/API / 培训 / 基础设施 / 推广运营】

目标定了，立项要算清要多少钱。成本分四块。其一，工具和 API——人均月费乘人数乘月数，Claude Code 订阅或模型调用。其二，培训——2 天全员脱产加讲师，工时成本。其三，基础设施——大团队要 RAG、知识图谱服务器加架构师。小团队可跳过。其四，推广运营——度量工具、试点激励、考核绑定，轻量。四块加起来就是总投入。

【内容保真（E03 脚本 cost 段，禁改写）】
成本 4 块（其一/其二/其三/其四，禁"第一块"）：
① 工具/API = 人均月费 × 人数 × 月数（Claude Code 订阅 / 模型调用）
② 培训 = 2 天全员脱产 + 讲师（工时成本）
③ 基础设施 = RAG / 知识图谱服务器 + 架构师（大团队；小团队可跳过）
④ 推广运营 = 度量工具 / 试点激励 / 考核绑定（轻量）
四块加起来 = 总投入
