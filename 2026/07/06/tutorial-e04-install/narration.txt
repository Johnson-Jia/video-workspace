工具选定，怎么装？以 Claude Code 为例。Mac 系统，打开终端，敲一行命令：curl 加 install.sh 地址，管道接 bash——一行装好。Windows 系统，用 PowerShell，命令一样简单。装完，终端回显安装成功。接着配认证。国内推荐用智谱 GLM——国产模型，国内直连，免费额度够练手。去智谱开放平台注册，创建一个 API Key。然后回到终端，设两个环境变量：头一个 BASE_URL，填智谱的兼容地址；第二个 AUTH_TOKEN，填刚拿到的 Key。两个变量敲完，终端敲 claude 启动——连接成功，直接能用。下一件事，是把团队规范写进 CLAUDE.md，让 AI 每次自动遵守。
