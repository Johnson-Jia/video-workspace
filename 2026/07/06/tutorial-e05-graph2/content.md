# E05 段4 · 图谱工具 + 两条铁律（基础设施第二件套续，核心段）

> 横屏 16:9 教程段，核心组件——impact 终端窗口（爆炸半径分析）+ 两条铁律卡。讲十四工具三类 + impact 演示 + 两条铁律 + 实测效果。

## 旁白（E05 脚本 段4 原文）

图谱建好，暴露给 AI 的是十四个工具，分三类：理解类，看清结构，比如 context 看符号的 360 度视图。变更类，评估影响，impact 算爆炸半径，detect_changes 把 git diff 映射到受影响符号。查询类，自由 Cypher 图查询，补图谱的盲区。有两条铁律，必须写进 AI 的指令：第一，改任何符号前必跑影响分析；第二，提交前必跑变更映射。这两条是基础设施能不能落地的命脉。实测效果：某团队用它排查生产 bug，跨仓库定位调用链，累计排查 144 个 bug，覆盖率超过八成。

## 视觉设计（核心：impact 终端窗口）

- 主体：impact 终端窗口（深底 + 标题栏红黄绿 + 命令打字 + 输出 fade-in + HIGH 红色脉冲）
- 底部：两条铁律卡片（金边 + 警示图标）
- 右侧：实测效果数据卡（144 bug · 80%+ 覆盖率）

## 关键内容锚点（保真，禁改写）

- 十四个工具分三类：
  - 理解类：看清结构（context 看符号 360 度视图）
  - 变更类：评估影响（impact 算爆炸半径 / detect_changes 把 git diff 映射到受影响符号）
  - 查询类：自由 Cypher 图查询（补图谱盲区）
- 两条铁律（必须写进 AI 指令）：
  - 第一：改任何符号前必跑影响分析
  - 第二：提交前必跑变更映射
- 这两条是基础设施能不能落地的命脉
- 实测效果：某团队用它排查生产 bug，跨仓库定位调用链，累计排查 144 个 bug，覆盖率超过八成

## 终端演示内容

```
$ impact --target UserService.validateToken
⚡ 爆炸半径分析中...

  风险等级: HIGH ⚠

```
