## 场景分镜（6 场景）

### 场景 1 — Hook + ai-job-search（涨星王）
- 情感内核：求职这件个性化的事居然能整成框架让 AI 跑
- 观众感受：冲击 + 好奇（求职都能 AI 代跑？）
- 视觉手段：暖橙光晕 punch-in + 2402 涨星数字大字 + "AI 代跑求职"反直觉文案
- 相邻反差：开场高能 → 场景 2 回落
- 视线焦点：涨星数字 → 项目名 → 用途胶囊

### 场景 2 — meetily 霸榜带过（3-4s）
- 情感内核：连续霸榜，增量信息"又涨了近一千八"
- 观众感受：熟悉感 + 信任（老朋友又回来了）
- 视觉手段：快速带过，星标数字 + "霸榜"标签，不展开功能
- 相邻反差：场景 1 高能 → 此处回落 → 场景 3 再升
- 视线焦点：星标数字 + 霸榜标签

### 场景 3 — pocket-tts（CPU 跑 TTS）
- 情感内核：TTS 通常吃 GPU，这个 CPU 6x 实时跑

- 相邻反差：场景 2 低 → 此处升
- 视线焦点：CPU 图标 → 反直觉胶囊 → 项目名

### 场景 4 — OfficeCLI（命令行操 Office）
- 情感内核：Office 居然有命令行版还能给 AI 用

## 视觉安全
- 卡片背景深色不透明 rgba(13,9,5,0.88)（挡 fx 光晕透字，alpha≥0.7）
- 渐变文字用橙金渐变（#FF8C42→#FFB347），禁白色端点
- 安全区 padding 单层（180/90/220/90），双重 padding 门禁
- 三层架构：bg（基底网格/光晕）+ fx（粒子/光晕）+ content（ProjectFullCard）
- 字号最低标准：项目名 60px+，正文 36px+，数字 92px+（竖屏）
