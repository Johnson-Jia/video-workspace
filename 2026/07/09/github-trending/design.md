## §1 视觉风格定位

**沉浸模式**：`hidden-gem`（工具/效率选题，跨领域宝藏工具集，温暖光效 + 渐进揭示）
- 避开近期 hyper-pace（连续 4 期 AI-Agent 用过，疲劳）
- 工具/效率题材适合温暖、聚焦、揭示感，强调"宝藏工具"而非"快速剪辑"
- 视觉主调：暗色科技底 + 跨领域强调色（每场景一个领域色，破同质化）

**整体调性**：暗色科技 + 跨领域工具箱。背景深蓝/深紫渐变基底，每个场景用不同强调色对应工具领域（设计=橙、视频=青、研究=蓝、3D=绿、文档=金），形成"工具箱开箱"的渐进揭示感。

## §2 配色方案（暗色科技 + 跨领域强调色）

### 基底（全局）
- 主背景渐变：`linear-gradient(135deg, #0B1426 0%, #1A1B3E 50%, #0F1B2D 100%)`（深蓝→深紫→深蓝灰）
- 文字主色：`#F1F5F9`（slate-100，高对比白）
- 文字次色：`#94A3B8`（slate-400）
- text-shadow：`0 2px 6px rgba(30,41,59,0.08)`（极淡 drop，禁发光）

## §6 沉浸模式实现要点（hidden-gem）

- **渐进揭示**：每场景用 GSAP .from() 让内容从 scale 0.95 + opacity 0 → 1，配合 fx 光晕从中心向外扩散
- **温暖光效**：fx 层用 radial-gradient 光球 + 轻微漂移（不是霓虹硬闪），温度感
- **跨领域色**：每场景主强调色不同，通过 CSS 变量 --accent 切换（场景级），避免全局同色
- **节奏**：标准模式 6-8s/场景，hook 3-4s，CTA 收束——不赶不拖

## §7 安全规范（渲染安全铁律）

- 根组合：`data-width="1080" data-height="1920"`（竖屏 portrait）
- 安全区 padding 单层：`padding: 180px 90px 220px 90px`（竖屏标准）
- 三层架构：每个 .scene-wrap 含 .layer-bg(z:1) + .layer-fx(z:2) + .layer-content(z:3)
- bg 层多样性：每场景渐变 + 至少一种纹理/光效（噪点/等高线/光束/扫描线/波纹），禁只 gradient+blur+grid 三件套
- fx 层：每场景至少 2 个特效元素（光球 + 粒子/射线），有 GSAP 动画
- 入场动画：GSAP .from()（opacity:1 默认，禁 CSS opacity:0 入场）
- 注册 timeline：`window.__timelines['main'] = tl`
- 字符：Unicode 直接输入（★ 不是 &#9733;）
