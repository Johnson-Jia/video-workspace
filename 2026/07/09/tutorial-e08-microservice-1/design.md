### 颜色

- bg：hex_grid（玻璃网格 + 同色系蓝 shimmer，禁白端点）
- 主色：深蓝 #0a0a1a 底
- 强调色：蓝紫渐变（#4a6cf7 → #8b5cf6）高亮前 3 Agent
- 灰色：后 3 Agent #4a4a5a（预告，低饱和）
- 文字：白字（90%）+ 渐变同色系（蓝紫，禁白端点）

### 字体

- 标题：64px 渐变（蓝紫渐变）+ text-shadow 深蓝 rgba(30,41,59,0.6)
- Agent 节点名：32px 白字
- 描述：22px #c0c0d0
- 警示条：24px 暖黄 #fbbf24（与冷主色对比）

### fx（冷色，禁划过类）

- fx-aura ×2（蓝/紫，alpha 0.18，静态光晕）
- fx-particle ×1（蓝粒子，飘散，alpha 0.15）
- 共 3 元素，全部冷色，alpha≤0.22

## 视觉分镜（visual_phases）

- phase 0（0-8s）：标题 + 横向 vs 纵向对比图淡入（stagger）
- phase 1（8-20s）：顶级 Agent 节点显现 + 四职责（语音需求/语义解析/任务分发/异常兜底）逐个高亮
- phase 2（20-40s）：六专项流水线登场，前 3（需求定位/接口规划/代码生成）高亮，后 3 灰色预告
- phase 3（40-60s）：前 3 专项描述展开（RAG+代码图谱 / 复用优先 / Controller+Service+Mapper）
- phase 4（60-85s）：警示条"成熟期愿景，不是起步就建"显现 + 整体收尾

## 铁律遵守

- DOM 三层（scene/phase/元素）+ GSAP 单 timeline
- composition 完整：__timelines 独立注册，禁 repeat:-1
- phase 可见性：CSS opacity:0 + GSAP 切换
- 禁 CSS class 切换可见性（防黑屏）
- 渐变文字 text-shadow 深蓝（非发光 0 0 Xpx）
