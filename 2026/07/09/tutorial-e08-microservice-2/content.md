## 核心知识点

### 后三个专项 Agent（接 microservice-1 的前三个）
- **自检查**：对照开发规范校验生成代码，输出报告 + 修改建议，直到合规
- **测试**：生成自动化测试用例并执行，不过则回传代码生成 Agent 优化（闭环箭头）
- **部署**：测试通过后自动提交代码、部署到对应环境

### 数据底座（阶段三建）
- **RAG 向量库**：存业务数据（供 Agent 检索业务上下文）
- **代码知识图谱**：存代码结构（供 Agent 定位模块、复用接口）

### 人机边界
- **人**：定义需求 + 审核决策
- **AI**：执行全流程
- 流水线定位：AI 主导重复工作，人聚焦核心决策

### 警示（收尾）
- **先跑通阶段零到五**（思想/战略/培训/基础设施/闭环试点/度量）再演进，否则空中楼阁
- 数据和规范底座是演进前提

## 教学要点
1. 后三个 Agent 与前三个（microservice-1 段）共同构成六专项流水线闭环
2. 测试 Agent 不过 → 回传代码生成 Agent，形成"测试驱动的自我修正"闭环
3. 数据底座（RAG + 代码图谱）是流水线智能的根基，阶段三建
4. 人机边界明确分工：人决策、AI 执行
5. 警示条强调务实路径：先有底座（阶段零到五）再演进流水线
