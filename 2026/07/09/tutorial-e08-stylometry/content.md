# content.md — E08 段4 第二层 风格学（stylometry，算法流程核心段）

## 段落定位

E08（AI 代码占比度量）第二段核心 —— 风格学反伪造。在首层 Co-authored-by 初筛之后，对被标记提交做风格相似度复核。

## 旁白原文（来自脚本段4，~85s）

第二层是反伪造关键——风格计量学。原理：每个开发者有独特的代码风格指纹，AI 生成的代码风格往往和作者本人不一样。对被 Co-authored-by 标记的提交，算它和作者本人风格画像的余弦相似度。算法四步：字符级 n-gram 切分，TF 归一化，算余弦相似度，置信度等于一减相似度。像本人手写的，相似度高，可能是误标，降低置信度；不像本人的，相似度低，确认是 AI。这样能挡住 VS Code Copilot 对手写代码加 trailer 这类误标。

## 视觉

四步横向流程图：字符级 n-gram 切分 → TF 归一化 → 余弦相似度 → 置信度 = 1 − 相似度。再分两支：相似度高 → 可能误标降置信度；相似度低 → 确认 AI。

圆/胶囊节点内仅短词（n-gram / TF / 余弦 / 置信度），长描述移容器外（container_text 规则）。
