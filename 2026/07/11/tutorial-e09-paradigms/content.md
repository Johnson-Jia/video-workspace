# E09 paradigms 段 · 七种 Skill 范式（核心段）

## 段落定位
- 合集：AI 转型实战教程 E09（Skill 范式整合：个体经验变组织资产）
- 段类型：paradigms（七种 Skill 范式，七卡片核心段）
- 时长目标：约 90 秒
- 横屏 16:9，分辨率 1920×1080

## 核心信息
七种 Skill 范式各管一摊：
1. 工具型：封装高频开发动作（SQL 查询、CRUD 生成），业务开发团队最爱
2. 规范型：让 AI 输出符合团队设计规范，前端团队统一 Token
3. 平台型：低代码搭建，严格触发条件加接口白名单，绝不猜测写操作
4. 流程型：AI 分析变更生成规范提交，自动提交
5. 记忆型：持久化记忆跨会话复用，按项目隔离
6. 诊断分析型：只读分析不改代码，性能诊断、慢 SQL 定位（区别于工具型会改代码）
7. 编排型：自己不实现，把多个 Skill 串成流水线（devflow 编排 OpenSpec + Superpowers 成六阶段）
