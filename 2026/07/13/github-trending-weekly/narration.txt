第29周，AI agent 冲上 GitHub，单这一周就涨一万多星。
先看编码 agent 这组，给做编程的开发者。stablyai 的 orca 让多个 agent 并行写代码，桌面和手机都能跑，这周涨了四千四。herdr 住在终端里同时管多个 agent，codex-plugin-cc 让两家 AI 互相审代码派任务，DesktopCommanderMCP 给 agent 装上终端和文件控制能力。
接着技能生态这组。caveman 用穴居人语气说话，能省六成五词元，总星八万八，是这组的元老。claude-skills 收了三百四十五个技能和插件。claude-video 让 agent 能看懂视频，这周涨了四千三。archify 一句话就画出架构图。
安全工具这组讲的是防御价值。strix 帮开发者提前找出应用里的漏洞再修复，这周涨了四千一。pentagi 是全自动的渗透测试 agent。CubeSandbox 给 agent 一个隔离沙箱，防止它乱跑搞破坏。
应用办公这组普通人也能上手。OfficeCLI 让 agent 直接读写 Word 和 Excel，单文件就跑，这周涨了近七千星，是这周的涨星王。page-agent 用一句话控制网页界面。astryx 是一套 agent 就绪的设计系统。
这周 GitHub 的信号很清楚：agent 不再是散装工具，开始成体系了，从写代码到找漏洞再到接管办公，都有了对应方案。这周的项目你会试哪个？关注 GitHub 星探，下周见。
