## 核心主题
为什么是 prompt 包不是工具——prompt 是内容资产，三个特点。

## 关键信息点
- 其一：用任意 AI，不绑定 Claude Code 或特定工具（ChatGPT/Claude/GLM 都行）
- 其二：prompt 是内容资产，可单独交付、可独立卖；工具是可选渲染层，能替换
- 其三：可复制，拿 prompt 加自己数据，照做即生成，不靠灵感
- 整个目录自包含：五个 prompt 加一份说明
- 可独立打包分发或售卖
