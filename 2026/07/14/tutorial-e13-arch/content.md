# 内容摘要

## 来源
合集脚本 E13（AI 自动化测试实操，ai-test-frame 开箱跑，合集收官集）架构总览段（段1）。对应教程 demos/ai-test-frame。

## 核心主题
ai-test-frame 框架八个文件的全景架构总览，对应五个核心思想。八个文件各司其职：注册中心、软断言、测试基类、调度器、业务处理器、执行入口、用例数据、被测页。

## 八个文件（来自 README §架构）
1. registry 注册中心 — 装饰器登记用例类型
2. assertions 软断言 — 失败不中断加截图加收集
3. base_page 测试基类 — 封装通用操作和通用定位
4. runner 数据驱动调度器 — 读用例按类型路由
5. handlers 具体业务处理器 — 这里只放商品管理一个示例
6. main 执行入口 — 开浏览器跑用例汇总
7. data 用例数据 — 运营在这里编步骤
8. site 被测页 — 自带极简商品管理页开箱跑

## 五个核心思想（README §关键思想）
- AI 只生成不执行
- 数据与代码解耦
- 注册中心模式
- 软断言
- 变量传递
