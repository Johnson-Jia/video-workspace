# Design — 第32周 GitHub 周榜

> 日期：2026-08-03 | 分类：github | 模式：weekly 周汇总 | 竖屏 portrait 9:16

## 1. 风格方向 style_direction

暗色科技风。基底深蓝/深紫渐变，强调色橙+蓝双光晕。周榜多项目盘点节奏快，视觉信息密度高但层次清晰：每组用领域色环/边框/标签做视觉分组（仅视觉，旁白与画面文字禁说颜色词），项目卡用 ProjectFullCard 一屏一项目轮播。

## 2. 配色 color_palette

| 用途 | 色值 | 说明 |
|------|------|------|
| 基底 | `#0B1020 → #1A1140` | 深蓝→深紫渐变 |
| 主强调 | `#FF8C32` | 橙（数字爆点/CTA） |
| 副强调 | `#4DA8DA` | 蓝（科技感主色） |
| 文字主 | `#F8FAFC` | 近白（高对比） |
| 文字次 | `#94A3B8` | 灰蓝（辅助信息） |

**领域分组配色（仅视觉，旁白禁颜色词）**：
- AI 编程与代码审查 → 蓝 `#4DA8DA`
- 给 AI 助手加技能 → 橙 `#FF8C32`
- AI 接入与创意 → 青 `#22D3EE`
- 隐私通讯与 3D/学习 → 金 `#FBBF24`

**⛔ 渐变文字（background-clip:text）**：禁白色端点，用同色系高饱和（橙 `#FF8C32→#FB923C→#FDBA74` / 蓝 `#4DA8DA→#60A5FA→#93C5FD` / 金 `#FBBF24→#F59E0B→#FCD34D` / 青 `#22D3EE→#67E8F9→#A5F3FC`）。

**⛔ text-shadow**：极淡 drop `text-shadow: 0 2px 6px rgba(30,41,59,0.08)`，禁发光 `0 0 Xpx`。

## 3. 沉浸模式 immersion_mode

`hyper-pace` — AI 类项目占比 >50%（13个里8个AI编程相关），快速剪辑 + 密集粒子 + 霓虹蓝主调。周榜盘点节奏紧凑，每组 10-12s 内 3-4 项目卡快速轮播。

## 4. 字体 typography

无衬线粗体。标题/数字用粗体大字号，正文用中等字重。项目名（英文）与数字用等宽或半粗体强化科技感。中文字体 PingFang SC / 思源黑体。

## 6. 视觉规则

- **竖屏优先**：所有场景按 9:16 portrait 设计，安全区内布内容
- **ProjectFullCard**：一屏一项目，顶部用途利益标签（pfc-use，如"AI帮审代码""省内存跑AI编程"），中部 owner avatar 引用，项目名+星数+中文描述
- **组标题页**：每组开场 1-2s 组标题（领域名，非颜色词），配领域色环/边框做视觉切换信号
- **数字爆点**：星数/项目数用大字号橙金强调（59K★ / 290+模型 / 8个）
- **节奏**：hyper-pace 快剪，每项目卡 2.5-3.5s，组间用领域色切换做断点
- **角色**：启用码力角色（github character_presence=true），hook 场景 shock 表情，CTA 场景 invite 表情

## 7. 安全区与渲染

- portrait 安全区：内容落中 80% 区域，避免抖音上下裁切
- 渲染前过 render-safety：禁低质 glow + 空 fx，fx 最低 ≥2 不同类型
- bg/fx：深色不透明底 + 双光晕（暖冷色调），组件透明卡用深色不透明底避免与 bg 冲突
