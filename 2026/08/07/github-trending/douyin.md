## B站

8月7日GitHub四个项目杀入榜单，一半不是AI：guava·authentik·code-review-graph·loopx

8月7日 GitHub 热门盘点，本期一个反差：四个项目里 AI 只占一半。

guava — Google 的 Java 核心库。集合、缓存、并发全打包，51.6K 星，Java 程序员几乎绕不开的基础设施，十几年的老库今天还在涨。

authentik — 开源身份认证中台。支持 OIDC/SAML/LDAP 单点登录，Docker 一键部署，登录账号自己管不依赖第三方，23K 星。

code-review-graph — 本地优先的代码知识图谱。给代码库建持久化地图，AI 审代码只读关键部分，上下文显著减少，专治大仓库审查，29K 星。

loopx — 给长跑 AI agent 团队做的轻量状态内核。持久化目标、配额自动唤醒、任务可追溯，跨多种编码 agent 通用，今日 +854 星涨得最猛。

近 3 期连续 AI 之后，这期非 AI 基建（认证 + Java 库）回归占了一半。

这四个你会用上哪个？关注我，下期见。
