## style

清爽专业科技风·核心方法论段。本段信息密度最高——价值翻译对照表、干系人四角色 + 决策链、汇报四块，靠结构化卡片和清晰布局承载，不靠花哨动画。深蓝底 + fx-aura 静态光晕（禁划过类 fx，教程重内容轻视觉）。受损方角色卡用红色 fx-pulse-ring 脉冲（alpha 0.20 ≤ 0.22）警示，其余角色静态色块。

## storyboard

### narrative_template

核心方法论三幕（FDE 五件事中的第三/四/五件）：
1. **价值证明**（用数据说话）：hook 锚点「省了多少」→ 技术指标翻译成业务收益对照表（96%分流→82→96 / 6分钟→2分钟 / 月省5800工时，示意脱敏）→ 度量基线必须演示前采（严谨提醒）
2. **干系人管理**（失败头号暗礁）：结构性冲突总览（四类冲突）→ 四步法（识别人/判受益受损/摸决策链/定策略）→ 受损方警示（质检组长案例 + 参与式设计 + 复核岗）→ champion 推动者 + 验收口径书面确认
3. **汇报表达**（把价值讲清楚）：业务语言翻译（少架构图多收益数字）→ 汇报四块（现状痛点/目标/试点结果/下一步）

### emotion_curve

[0.85, 0.70, 0.55, 0.78, 0.60, 0.90]

> 节奏：hook「省了多少」价值冲击开场（0.85）→ 价值翻译数字落地理性（0.70）→ 度量基线严谨回落（0.55）→ 干系人结构性冲突暗礁紧张上升（0.78）→ 四步法方法梳理沉稳（0.60）→ 受损方警示 + champion + 汇报务实收束在高位（0.90）。

### immersion_mode

教程横屏 reveal — 每场景单 phase + 多 region data-reveal 同屏累积。三幕组件依次入场：价值翻译对照表 reveal 后保持在场，干系人四角色卡 + 决策链依次 reveal，汇报四块卡收尾。信息密集段靠同屏累积承载，不频繁换屏。

## 视觉区域范式

### 场景 1：价值 hook 锚点（~5s，「省了多少」）

- **hook 大字区**（data-reveal=0）：金色渐变大字「客户买单·不看技术指标·看省了多少」+ 蓝白小字「价值证明 · 用数据说话」
- **fx-aura**：金色静态光晕脉冲（alpha 0.18 ≤ 0.22，禁划过类）

### 场景 2：价值翻译对照表（~22s，技术→业务）

- **对照表区**（data-reveal 错时）：左侧蓝框「技术指标｜分流准确率 96%」→ 箭头 → 右侧金框「业务收益」三行（准确率 82%→96% / 单条 6分钟→2分钟 / 月省 ≈5800 工时）
- **口径标注区**（data-reveal）：蓝白小字胶囊「示意口径 · 虚构脱敏 · 非真实客户」
- **fx-blink**：箭头锚点点缀

### 场景 3：度量基线提醒（~14s，严谨）

- **基线卡区**（data-reveal=0）：蓝色框「度量基线 · 演示启动前必须采」+ 三项列表（转型前准确率 / 处理时间 / 工时）+ 红色警示行「否则上线后无对比基准·回报客户不认」
- **fx-aura**：蓝色静态光晕

### 场景 4：干系人冲突总览（~11s，暗礁）

- **冲突总览区**（data-reveal 错时）：标题「干系人管理 · 项目失败头号暗礁」+ 四类冲突横排（业务领导 vs 技术部门 / 采购卡流程 / 一线怕被替代 / 中层怕担责），每类小标签
- **fx-aura**：深色静态光晕（紧张感）

### 场景 5：四步法（~18s，方法梳理）

- **四步法箭头区**（data-reveal 错时 2s 依次）：横向四步流水线节点 flex:1 撑满——「① 识别人」「② 判受益受损」「③ 摸决策链」「④ 定策略」，每节点短说明（识别人含不发声否决者 / 受益受损权力工饭碗 / 决策链签字否决预算验收 / 受益推动中立背书受损争取中和）
- **fx-blink**：当前步骤锚点

### 场景 6：受损方警示（~22s，暗箭案例）

- **干系人地图区**（data-reveal 错时）：四角色卡 2×2 grid——「业务领导·受益 绿」「IT·中立 灰」「一线质检·受损 红（fx-pulse-ring 脉冲 alpha 0.20）」「采购·卡流程 黄」+ champion 金色星标 + 决策链连线（谁签字/谁否决）
- **案例卡区**（data-reveal）：蓝色框「质检组长（示意案例）·怕被替代暗中抵触」→ 处理方式「参与式设计 + AI 结果复核岗」+ 金句「AI 是帮你的，不是替你的」
- **fx-pulse-ring**：仅受损红卡脉冲（alpha 0.20 ≤ 0.22），其余角色静态

### 场景 7：champion + 验收（~12s，推动者）

- **champion 卡区**（data-reveal=0）：金色框「champion · 客户内部有话语权的推动者」+ 「要有备手 · 一离岗项目立刻失速」+ 蓝色行「验收口径 · 演示启动前书面确认 · 防中途被偷改」
- **fx-aura**：金色静态光晕

### 场景 8：汇报四块（~18s，务实收束）

- **汇报四块卡区**（data-reveal 错时）：横向四块卡 flex:1 撑满——「现状痛点」「目标」「试点结果」「下一步」，标题蓝框 + 内容金色收益数字高亮
- **金句区**（data-reveal）：蓝白「少放架构图 · 多放收益数字」
- **fx-blink**：四块锚点平衡构图

## 动画策略

- **卡片 fade-in + slide**：opacity 0→1 + translateX/Y 8px→0，500-600ms ease-out（克制）
- **对照表箭头 reveal**：箭头从左向右描边动画，承接"翻译"动作
- **数据数字 count-up**：收益数字（96% / 5800）轻微 count-up（克制，不做强冲击）
- **四步法依次 reveal**：data-reveal 错时 2s，横向节点 flex:1 撑满
- **fx-pulse-ring 脉冲**：仅受损红卡，opacity 0.4→0.6 循环呼吸（alpha 0.20 ≤ 0.22），不划过不追线
- **fx-aura 静态光晕**：脉冲呼吸，不划过类
- **禁**：fx-scan/fx-stream/fx-beam 划过类、粒子过载、3D 翻转、强切换
