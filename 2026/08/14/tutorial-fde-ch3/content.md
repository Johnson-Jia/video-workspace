# content.md — FDE 番外篇 · ch3 段（技术武器库重映射）

## 段落定位

FDE 番外篇第 6 段。前面十三集主教程给了技术武器库（RAG / 多 Agent / 测试 / 度量 / Skill 五个 demo），本段讲这些武器在**客户现场的用法重映射**——不讲 demo 本身怎么跑，只讲 FDE 什么时候用、怎么改造适配客户，每个 demo 一句话。素材来自 `pages/fde.html` 第 3 章（3.1-3.5）。

## 五张武器卡（视觉主体：五卡横排 grid）

| demo 名 | 何时用 | FDE 改造要点（一句话） |
|---------|--------|----------------------|
| rag-service（RAG） | 客户有文档知识库要用 AI 查答 | 现场版加三层：数据脱敏 / 权限隔离 / 结果回写留痕，评估换成客户业务答准率 |
| agent-teams（多 Agent） | 客户场景复杂、一个智能体搞不定 | 按客户真实流程拆阶段，职责用客户听得懂的话命名 |
| ai-test-frame（测试框架） | 防止 AI 改一处坏一片 | 回归用例用客户真实场景，软断言阈值和客户当面定、写进验收标准 |
| ai-metrics（度量工具） | 向客户证明回报 | 客户最在意省了多少人多少钱，基线必须前置（演示启动前采） |
| claude-skills（Skill） | FDE 沉淀现场经验 | 把每个客户现场的通用经验沉淀成 Skill，下个客户直接复用 |

## 关键对比（增补段 + 底部总结条）

- **RAG 对比**：主教程用示例数据、看重排分数评估；现场版多加三层（脱敏/隔离/回写），评估换客户业务答准率——一个在自己的沙盒里玩，一个要在客户真实数据上跑
- **Skill 对比**（底部总结条）：主教程沉淀的是怎么写代码 / FDE 沉淀的是怎么搞定这类客户（如行业工单分流标准口径、遗留系统对接踩坑）
- 资深 FDE 和初级 FDE 的效率分界就在 Skill 沉淀

## 数据严谨性（教程规范）

- 「客户最在意省了多少人、多少钱」为经验观察表述，不绝对化
- 无精确统计数字，无媒体转引数据（本段无数据钩子）
