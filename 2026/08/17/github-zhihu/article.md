### 一、AI 智能体 & 工作流（本周主线）

#### 1. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

**项目简介：** 一套为 Claude Code 打造的**编辑级图表模板库**——29 种自包含的 HTML + SVG 图表类型，覆盖流程图、架构图、时间线等常见形态。它的定位不是"又一个画图工具"，而是给 AI 编码助手提供"画得好看"的起手素材：模板自包含、无外部依赖，AI 拿到就能直接改。

**核心亮点：**
- **29 种编辑级版式**——强调出版物质感的排版规范，避开了 Mermaid 类自动布局常见的"机器味"输出
- **自包含 HTML + SVG**——单文件即可渲染，不拉外部脚本，嵌进文档、网页、Issue 都能直接显示
- **面向 AI 编码工作流**——配合 Claude Code 的 Skills 机制使用，AI 能按模板语义快速产出成套图表

**快速上手：** 仓库为纯静态模板，clone 后直接打开任一 HTML 预览；按 README 的 Skills 安装说明挂进 Claude Code 即可调用。

**适合人群：** 重度使用 AI 编码助手、需要高频产出架构图/流程图的开发者与技术写作者。

> Star: 19,413 | Fork: 1,186 | 协议: MIT | 语言: HTML | 本周涨幅: +14,735

#### 2. [PrimeIntellect-ai/prime-agent](https://github.com/PrimeIntellect-ai/prime-agent)

**项目简介：** 一个主打**自我改进（self-improving）**的 RLM 智能体，面向编码工作流和长周期任务。它的核心叙事是"越用越强"——智能体在完成任务的过程中沉淀经验并反哺自身策略，而不是每次都从同一个起点出发。

**核心亮点：**
- **RLM（强化学习模型）驱动**——用强化学习而非纯提示词工程来演进 Agent 行为，路线与主流 prompt-based Agent 形成差异
- **长周期任务设计**——面向需要持续运行、多阶段推进的编码工作流，而非一次性问答
- **背靠去中心化训练团队**——PrimeIntellect 长期做大规模分布式训练基础设施，工程能力有积累

**快速上手：** TypeScript 实现，按仓库 README 的安装指引部署；建议先在隔离环境跑通示例任务再接入真实代码库。

**适合人群：** 研究 Agent 自我改进机制、构建长周期编码智能体的算法与平台工程师。

> Star: 16,521 | Fork: 1,779 | 协议: MIT | 语言: TypeScript | 本周涨幅: +8,488

**适合人群：** 做 AI Agent 产品、需要团队级记忆与知识治理的企业技术团队。
