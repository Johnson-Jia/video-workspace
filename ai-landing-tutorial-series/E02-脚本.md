# E02 · 思想转变与 AI 原理：转型第一步不是上工具

> 时长 10-12 分钟 | 横屏 16:9 | 对应教程 stage0.html（§1 §2 §3）
>
> 合集第二集。E01 讲了方法论全景 + 为什么转，E02 深入 stage0 地基——**思想转变的正确姿态 + 懂 AI 原理**。这是后续所有阶段的地基：不解决"想不想转 + 懂不懂原理"，后面工具/流程/度量都白搭。
>
> 钩子定位（反常识）：很多人觉得"AI 万能，全交给它就行"——错。AI 不是万能的，**人是根本**。这集讲清为什么，以及懂哪 5 条原理就能让交互效率天差地别。

**[画面：两个极端对比卡——左"抗拒 AI"右"盲目崇拜"，各列表现+代价，data-reveal]**

**旁白**：先讲思想转变。转型里最容易栽的两个坑，刚好是两个极端。

**[画面：左卡 reveal——抗拒 AI]**

**旁白**：一端是抗拒。觉得 AI 是噱头、怕被替代，碰都不碰。半年后回头发现，不是 AI 替代了你，是会用 AI 的人替代了你——差距是数量级的。

**[画面：右卡 reveal——盲目崇拜]**

**旁白**：另一端是盲目崇拜。觉得它万能，全盘交付不验证。结果产出不可控，质量崩塌，最后还得人工返工。

### 段2 原理①：AI 本质（tutorial-e02-essence，~80s）

**[画面：原理编号大字"原理 ①" + 标题"AI 到底是什么"，reveal]**

**旁白**：原理一，先搞懂 AI 到底是什么。

**[画面：弱 AI vs 强 AI 对比 reveal]**

**旁白**：第一条事实：当前所有的 AI——包括 ChatGPT、Claude、GPT-5——全是弱 AI。擅长特定任务，但没有任何真正的理解和意识。强 AI，也就是 AGI，目前只是理论概念。所以"AI 不是万能的"不是吓唬你，是它的本质决定的。

**[画面：两大流派 reveal——符号推理(GOFAI) vs 神经网络]**

**旁白**：AI 有两大流派。一条是符号推理，用规则模拟逻辑——这条路已经被淘汰。另一条是神经网络，模拟大脑结构从数据里学——这是当前主流，大模型就属于这一类。

**[画面：图灵测试 reveal + 一句注解]**

**旁白**：怎么判断机器算不算智能？图灵测试——人分不清对面是人还是机器，就算通过。但注意：通过图灵测试不等于真有智能，可能只是巧妙的模仿。

> 画面意图：4 region（原理编号 / 弱vs强 / 两流派 / 图灵测试），data-reveal-dir="top" 从上到下渐进。弱vs强对比卡水平对称。

### 段3 原理②：预测下一个 token（tutorial-e02-token，~85s）

**[画面：原理编号"原理 ②" + 标题"大模型本质：预测下一个 token"]**

**旁白**：原理二，大模型的本质。一句话——它就是根据上文，预测下一个 token，也就是词元。

**[画面：token 预测动画——"今天天气真" → "好" reveal，逐字]**

**旁白**：比如你输入"今天天气真"，它预测下一个字大概率是"好"。它不是真的"理解"了你的代码，而是基于海量模式，生成最可能的续写。

**[画面：幻觉揭示 reveal——"一本正经地胡说"]**

**旁白**：这解释了一个关键现象——幻觉。AI 会一本正经地胡说，因为它生成的是"看起来对"的，不是"验证过对"的。

**[画面：金句 reveal——"所以必须验证" + count-up 0→100% 验证率飞升]**

**旁白**：所以从原理上你就明白了——AI 的产出，必须验证。这不是不信任，是它的运作方式决定的。信任但验证，根在这。

> 画面意图：4 region（原理编号 / token预测示意 / 幻觉揭示 / 必须验证金句）。token 预测用 data-count-to 或逐字 reveal。金句区可加 count-up 动画（验证率 0→100%）。

### 段4 原理③：上下文 1M（tutorial-e02-context，~75s）

**[画面：原理编号"原理 ③" + 标题"上下文窗口：1M 的约束"]**

**旁白**：原理三，上下文窗口。现在的模型上下文已经到 1M——一百万 token，听着很大。

**[画面：上下文桶 reveal——大代码库/长会话/MCP工具定义 把桶填满，count-up]**

**旁白**：但虽大，还是会填满。一个大代码库、一段长会话、一堆 MCP 工具定义，都会把它撑爆。一旦填满，性能就下降。

**[画面：最佳实践列表 reveal——精简CLAUDE.md / 按需Skill / 干净会话 / CLI优于MCP]**

**旁白**：这条原理是几乎所有最佳实践的源头。为什么要精简 CLAUDE.md？为什么要按需加载 Skill？为什么保持干净会话、能用 CLI 就别堆 MCP？全是在围着这一个约束转。上下文是稀缺资源，每一段常驻内容，都要挣它的一席之地。

### 段5 原理④⑤：Agent + REACT（tutorial-e02-agent，~100s）

**[画面：原理编号"原理 ④ ⑤" + 标题"Agent + REACT：让 AI 能动手"]**

**旁白**：原理四和五，是一对——Agent 和 REACT。大模型本身只能输出文字，它读不了文件、调不了接口、跑不了命令——没法真正动手。

**[画面：Agent 公式 reveal——大模型 + 工具 = Agent]**

**旁白**：怎么办？把大模型和一堆工具组装起来，让它能感知和改变环境——这就是 Agent。模型"先思考再行动"的奥秘，藏在系统提示词里——定义它什么时候调什么工具。注意，这靠的是提示词工程，不是模型训练。

**[画面：REACT 循环图 reveal——Thought→Action→Observation→循环→Final，四节点]**

**旁白**：Agent 怎么跑？靠 REACT 模式——这是最广泛的运行方式。四步循环：思考，基于当前观察想下一步；行动，选择工具加参数；观察，看执行结果；然后把这三者加回上下文，继续循环，直到给出最终答案。

**[画面：循环动效——四节点依次亮起 + 连线，repeat 呼吸]**

**旁白**：思考、行动、观察、再思考——AI 就是这样一圈圈跑下来，把一个复杂任务拆成可控的小步。理解这个循环，你就理解了 Claude Code 为什么能自主完成一整套开发任务。

> 画面意图：3 region（原理编号 / Agent公式 / REACT循环图）。REACT 循环是核心视觉——四节点放射或环形布局，data-reveal 逐节点亮起 + 连线，可用循环呼吸动效（不划过）。

### 段6 原理⑥：精准指令 + 人是根本（tutorial-e02-instruct，~85s）

**[画面：原理编号"原理 ⑥" + 标题"精准下达指令"]**

**旁白**：原理六，也是落地最直接的一条——精准下达指令。前面五条原理懂了，你下指令的方式就得变。

**[画面：差指令 vs 好指令对比 reveal——左红右绿]**

**旁白**：看个对比。差的指令："帮我优化一下这个功能"——没上下文、没目标、没验证标准。好的指令："这个接口慢 SQL 18 秒，附执行计划，目标降到 1 秒内。先分析瓶颈给方案，我确认后再改，改完用 EXPLAIN 验证"——给现状、明目标、定流程、要验证。

**[画面：金句 reveal——"像给聪明的实习生下指令"]**

**旁白**：一句话总结：像给一个聪明的实习生下指令——给够上下文、说清目标、定好流程、要求验证。模型越强，越需要你定义清楚做什么、为什么、怎么算对。

**[画面：收尾大字 reveal——"人 + AI，人是根本" + 五条原理缩略回显]**

**旁白**：五条原理讲完。你会发现，每一条都指向同一个结论——AI 能放大人的能力，但放大的是"会用 AI 的人"。人的能力边界，决定了 AI 产出的上限。人加 AI，人是根本。这就是为什么转型的第一步不是上工具，是转变思想、懂原理。

> 画面意图：4 region（原理编号 / 差vs好指令对比 / 实习生金句 / 人是根本收尾）。差vs好对比卡水平对称（左红右绿）。收尾大字居中，五原理缩略在下方小字回显（呼应全段）。
