### 补充评论（要点拆条，可分多条发）

1. 工具选型按角色不是一刀切。开发者首选 Claude Code——终端原生、自主执行、生态完整、超长上下文；产品经理和非开发选 OpenAI Codex——云端委托加 ChatGPT 集成，不必碰终端，适合做原型；国内团队想白嫖选 GLM——国产模型国内直连，免费额度够练手。选对工具是杠杆，选错再努力也补不回来。

2. Claude Code 一行命令装好。mac 用 curl，Windows 用 PowerShell。装完配认证，国内推荐用智谱 GLM——去智谱开放平台注册创建一个 API Key，设两个环境变量：ANTHROPIC_BASE_URL 填智谱兼容地址，ANTHROPIC_AUTH_TOKEN 填你的 Key，终端敲 claude 启动——国产模型国内直连，免费额度够练手。

3. CLAUDE.md 是规范资产化的起点。项目根目录的规范文件，AI 每次自动读取。写什么？技术栈（React + TypeScript + Vite）、命名规范（组件 PascalCase、工具 camelCase）、常用命令（改动必跑 npm test）、提交规则（约定式 feat/fix/docs）。AI 读一次，每次生成都遵守——人定规矩，AI 自动执行。提交进 Git 全团队共享，新人来了 AI 帮他守规矩。

4. 围绕 CLAUDE.md 还有四件，合称五件套。CLAUDE.md（项目规范，AI 自动读）/ Skill（可复用工作流，AI 按需调用）/ MCP（连接外部数据加工具，让 AI 能查库调接口）/ RAG（检索知识库减少幻觉）/ Hooks（事件钩子，自动跑检查加防护）。五件套是团队级提效的关键——个体再强，规范不沉淀就复制不开。

5. 推进治理别只发个工具就完。培训到百分之百覆盖，不留死角；周会同步进度，公开分享好用法；强制写周报，跟踪每人 AI 使用率加产出；考核引导循序渐进——赋能期只鼓励不惩罚。推进治理不到位，赋能就停在嘴上。
