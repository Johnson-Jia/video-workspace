## 脚本

### 开场（复用 tutorial-opening，~20s）

### hook（~30s）
**旁白**：工具选错，产出差一个量级。同样用 AI，有人效率翻倍，有人原地踏步——差别往往不在人，在工具。这集讲全员赋能：选对工具、装好 Claude Code、把团队规范变成 AI 能读的资产。

### intro（~30s）
**旁白**：全员赋能三件事：选对工具（按角色）、全员培训到全覆盖、规范资产化。三件事做到位，团队才算被赋能。这集前半段讲工具选型加安装，后半段讲规范资产化。

### 段1 工具选型（~80s，方法论卡片）
**旁白**：先讲工具选型。按角色选，不是一刀切。
- 开发者、工程师，首选 Claude Code——终端原生、自主执行、生态最完整、上下文最强。
- 产品经理、非开发，选 OpenAI Codex——云端委托加 ChatGPT 集成，不必碰终端，适合做原型。
- 国内团队想白嫖，GLM 性价比高，国产模型国内直连。
- 选对工具是杠杆，选错再努力也补不回来。

> 视觉：3 卡片（Claude Code 开发 / Codex 非开发 / GLM 国内），各列角色+优势。data-reveal stagger。

### 段2 安装 + 终端模拟（~90s，**终端窗口**）
**旁白**：工具选定，怎么装？以 Claude Code 为例。一行命令装好——mac 用 curl，Windows 用 PowerShell。

**[终端窗口 reveal]**
**[终端打字动画]**
```
$ curl -fsSL https://claude.ai/install.sh | bash
✓ Claude Code installed
```

**旁白**：装完要配认证。国内推荐用智谱 GLM——国产模型，国内直连，免费额度够练手。去智谱开放平台注册，创建一个 API Key。

**[终端配置打字]**
```
$ export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic
$ export ANTHROPIC_AUTH_TOKEN=你的智谱Key
$ claude
╭─ Claude Code ──────────────╮
│  ✓ 已连接 GLM，开始用吧     │
╰─────────────────────────────╯
```

**旁白**：两个环境变量：BASE_URL 填智谱兼容地址，AUTH_TOKEN 填你的 Key。然后终端敲 claude 启动——连接成功，直接用。

> 视觉：**终端窗口**（深底 #0a0a0a + 标题栏「Terminal — bash」+ 红黄绿圆点）。命令逐字打字（GSAP textContent）+ 输出 fade-in。⚠️ 只讲 GLM 配置（删 OAuth/中转/云厂商，避免信息过载）。禁 npm install（已废弃）。

### 段3 CLAUDE.md 资产化（~90s，**代码块**）
**旁白**：装好工具，关键是规范资产化。团队规范写进 CLAUDE.md——项目根目录的规范文件，AI 每次自动读取。

**[CLAUDE.md 代码块 reveal]**
```markdown
# 项目规范
- 技术栈：React + TypeScript + Vite
- 命名：组件 PascalCase，工具 camelCase
- 测试：改动必跑 npm test
- 提交：约定式（feat/fix/docs）
```

**旁白**：CLAUDE.md 写什么？技术栈、命名规范、常用命令、提交规则——AI 读一次，每次生成都遵守。这就是规范资产化：人定的规矩，AI 自动执行。提交进 Git，全团队共享，新人来了 AI 帮他守规矩。

> 视觉：**文件窗口**（标题栏「CLAUDE.md」）。代码块（等宽字 + 语法高亮：注释灰/键名蓝/值白）。逐行 reveal（data-reveal-dir=top，每行 stagger 0.5s）。

### 段4 五件套辨析（~80s，方法论卡片）
**旁白**：CLAUDE.md 是规范资产化的起点。围绕它还有四个件——合称五件套。
- CLAUDE.md：项目规范，AI 自动读。
- Skill：可复用工作流，AI 按需调用。
- MCP：连接外部数据加工具，让 AI 能查库调接口。
- RAG：检索知识库，减少幻觉。
- Hooks：事件钩子，自动跑检查加防护。
- 五件套是团队级提效的关键——个体再强，规范不沉淀就复制不开。

> 视觉：5 卡片（CLAUDE.md / Skill / MCP / RAG / Hooks），各列职责一句话。data-reveal stagger。

### 段5 推进治理（~70s，方法论卡片）
**旁白**：最后讲推进治理。赋能不是发个工具就完——要推到位。
- 培训到百分之百覆盖，不留死角。
- 周会同步进度，公开分享好用法。
- 强制写周报，跟踪每人 AI 使用率加产出。
- 考核引导，循序渐进——赋能期只鼓励不惩罚。
- 推进治理不到位，赋能就停在嘴上。

> 视觉：4 要点列表（培训100% / 周会 / 周报 / 考核引导）。data-reveal stagger。

### CTA（~30s）
**旁白**：工具装好、规范沉淀、团队赋能到位，下一步是给 AI 装上眼睛和记忆——基础设施。下集讲 RAG、代码知识图谱、Skill 仓库。合集 12 集，点关注不走丢。教程仓库在评论区。最后问你：你的团队，Claude Code 装上了吗？

## 制作提示（E04+ 新规则）

| 项 | 规则 |
|----|------|
| **BGM** | **一首贯穿**（各段 output_no_bgm concat + 整集一首 warm-editorial + volume 0.25 + 淡入淡出）。一首原长不够（E04 ~500s，warm-editorial 82s 需循环 6 次）→ **拼接多首同系列**（warm-1/2/3/4/5 各 82s 衔接到 500s），**衔接处必须淡入淡出**（afade 跨曲交叉淡化 2-3s，禁硬切）|
| bg | scan_grid（深蓝网格）|
| 字体 | 渐变端点亮 + text-shadow 极淡 0.08（rgba(30,41,59,0.08)）|
| 清晰度 | concat crf 14 |
| 终端/代码窗口 | 深底 #0a0a0a + 等宽字 JetBrains Mono + 打字动画 GSAP |
| 多音字 | 转→转型 / 藏→隐藏 / 2→两（tutorial.md 规则）|
| 禁"第一" | 用"起手/首个/其一" |
