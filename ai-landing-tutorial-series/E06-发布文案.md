### 简介

E05 讲了基础设施（给 AI 眼睛和记忆），这集进入实施第四关——闭环试点：把需求到交付串成一条命令，AI 自己跑完，中间断了还能接着干。这是合集里最有料的一集，闭环试点是整套方法论的核心发动机。

**核心**：多数人以为 AI 提效的关键是"让 AI 写更多代码"，这集说真正的发动机是**纠错左移**——把发现需求偏差从改代码左移到改一份 Markdown，交付质量提升一个数量级。

**你将学到**
- **三堵墙**：AI 初始分析不准 / 上下文断 / 偏差晚发现——串成端到端流水线会撞的三个坑
- **SDD 规范驱动开发**：三产物 spec(WHAT) / plan(HOW) / tasks(DO)，纠错左移的核心思想
- **OpenSpec 三概念四命令**：Spec 稳定 / Change 一次性 / Archive 归档 + explore/propose/apply/archive
- **六阶段流水线**：探索→规范→计划→TDD→验证→归档，每阶段一个 Superpowers skill 编排
- **断点续传**：tasks 清单状态机（[ ]→[in_progress]→[x]），中途退出重进扫 [x] 标记接着干
- **devflow 一条命令**：编排型 skill 把六阶段串起来 + 规则覆盖（rules/ 改写底层 skill 出口）
- **TDD + 子代理分工**：RED/GREEN/REFACTOR + Explore/实现/规格审/质量审四代理各司其职
- **随能力做减法**：入门 OpenSpec+Superpowers → 熟练 Superpowers → 精通 裸 Claude Code

**真实案例**：某业务组重构个人中心，12 个 Controller、211 个 API、约 1.5 万行、110 个任务，全靠 tasks 清单支撑跨周断点续传，中途退出重进看 [x] 标记接着干。

### 补充评论（要点拆条，可分多条发）

1. 闭环真正的发动机不是"让 AI 写更多代码"，是纠错左移——把发现需求偏差，从改代码左移到改一份 Markdown，交付质量提升一个数量级。AI 初始理解往往不准，但改 spec 比改代码快得多。SDD 三产物：spec.md（记 WHAT，可测试的行为规格，WHEN THEN 格式）/ plan.md（记 HOW，含完整代码的实施指南，每步前后对比加精确文件路径）/ tasks.md（记 DO，可追踪的 checkbox 任务清单）。

2. 端到端流水线会撞三堵墙。首堵，AI 初始分析不准——给它一句话需求，理解常常是偏的，照着偏的理解往下写越写越歪。第二堵，上下文断——AI 会话一中断，前面的分析、决策、进度全丢，重开等于从头再来。第三堵，需求偏差晚发现——等代码写完才发现理解错了，这时候改的是代码，返工代价极大。闭环就是拆这三堵墙：分析不准靠规范驱动纠错左移，上下文断靠 tasks 清单断点续传，偏差晚发现靠 spec 先行先验证。

3. OpenSpec 三个核心概念先分清。Spec 规格是稳定的、跨变更共享的，放 specs 目录；Change 变更是一次性的、做完归档，放 changes 目录；Archive 是变更完成后的存档。四条命令覆盖全流程：explore 探索需求调查代码库 / propose 生成 proposal、design、specs、tasks / apply 按 tasks 执行 / archive 验证通过后归档。关键一条：每次对话 OpenSpec 会自动读 specs 目录所有 spec 应用到生成代码，所以 specs 要精简，只放稳定的全局规范。

4. 断点续传靠 tasks 清单状态机。tasks 状态：空框待办、in_progress 进行中、x 完成、还有 deleted 和 blocked。关键在于：Claude 中途退出了，重进项目指定 change 目录，扫 tasks 的 x 标记就知道做到哪了，从下一个未完成的接着干。devflow 这个 skill 的恢复判定正是扫 x 标记自动恢复到正确阶段。某业务组重构个人中心：12 个 Controller、211 个 API、约 1.5 万行、110 个任务，全靠 tasks 清单支撑跨周断点续传（相关性非因果，事后统计）。

5. TDD 加子代理分工避免一个代理又探索又写又审的混乱。四种代理各司其职：Explore 代理只搜索只读不改；实现代理按 plan 精确指令改代码；规格审查代理对照 spec 逐条验证；质量审查代理查风格、安全、命名冲突。TDD 循环：RED 先写测试看它失败，GREEN 写最少代码让测试过，REFACTOR 重构。一条铁律：不要让 Claude 同时写代码和测试——它会写出验证错误逻辑的测试，全绿但全错。测试先行、独立验证。防偷改测试的具体护栏下集细讲。
