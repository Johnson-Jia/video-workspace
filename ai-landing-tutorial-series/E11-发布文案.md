### 简介

E09 讲了 Skill 范式的七种方法论，这集把范式落地——一组适配 Claude Code 的 skill 加 rule 仓库，4 个核心 skill 加 13 条团队规范，整个复制到自己项目就能跑。

**核心设计**：skill 按需调用，rule 始终生效，AI 自动遵守——团队经验从「个人会用」变成「组织默认能力」。

**你将学到**
- **Skill vs Rule**：skill 是可复用工作流，AI 按需调用（你让它做某事，它加载对应 skill）；rule 是始终生效的规范，AI 每次自动遵守（不用你提）。一个按需，一个始终
- **三件套结构**：SKILL.md 入口（声明干什么 / 怎么触发）→ reference/scripts 按需加载（细节放这，省上下文）→ rules 覆盖（可选，改写底层 skill 默认行为，适配团队规矩）
- **4 核心 skill**（覆盖编排 / 工具 / 审查三类）：
  - devflow（编排型）：需求到交付 6 阶段流水线，调 OpenSpec + Superpowers，断点续传 + 规则覆盖
  - sql-query（工具型）：PostgreSQL 只读查询，三模式 + 安全护栏（只 SELECT / 走 SSH 隧道 / 强制租户隔离）
  - crud-gen（工具型）：读表结构自动生成分层增删改查代码（domain → controller 一套）
  - code-review（编排型）：AI 审查 + 红黄绿三级分级 + 自动套 rule 规范
- **13 规范 5 层**：入口 team-conventions（CLAUDE.md 用 @ 引用所有 rule，AI 自动加载）/ 接口层（api-response、service-dao）/ 质量层（error-handling、logging、testing）/ 数据层（database、batch）/ 并发层（async、distributed-lock）/ 工程层（git-branch、naming）
- **安装实操**：Mac Linux 用 `cp -r`，Windows 用 `xcopy`，或直接拖文件夹；装完在 CLAUDE.md 用 @ 引用 rule，AI 自动加载

### 补充评论（要点拆条，可分多条发）

1. skill 和 rule 的区别是这套仓库的地基。skill 是可复用工作流加领域知识，AI 按需调用——你让它做某件事，它加载对应 skill；rule 是始终生效的规范，AI 自动遵守——不用你提，它每次都按规范来。一个按需，一个始终。比如 sql-query 是 skill，让它查数据时才调用；database 规范是 rule，每次写 SQL 自动按规范。两者配合，AI 既会干活又守规矩。

2. 一个 skill 的三件套结构。入口是 SKILL.md，声明这个 skill 干什么、怎么触发、调用什么；第二层是 reference 或 scripts，按需加载的详细资料和脚本，SKILL.md 只放骨架，细节放这里，AI 用到才读，省上下文；第三层是 rules 覆盖，可选，用来改写底层 skill 的默认行为，适配你团队的规矩。三件套让 skill 自包含、可复用、不臃肿。

3. 仓库里有 7 个 skill，这集挑 4 个核心讲。devflow 编排型（把需求到交付串成 6 阶段流水线）/ sql-query 工具型（PostgreSQL 只读查询，三模式加安全护栏）/ crud-gen 工具型（读表结构自动生成分层增删改查代码）/ code-review 编排型（AI 代码审查加红黄绿三级分级）。4 个覆盖了编排、工具、审查三类，团队最常用的高频操作基本都顾到。

4. devflow 是编排型 skill 的代表，自己不实现，把多个 skill 串成流水线。六阶段：探索 → 规范（调 OpenSpec）→ 计划（调 Superpowers）→ 测试驱动 → 验证 → 归档。它支持断点续传，中断了接着跑；支持规则覆盖，团队规矩能改写默认出口。devflow 把规范驱动开发从口号变成团队默认工作流。

5. 十三条团队规范按职能分五层，入口是 team-conventions 总纲，CLAUDE.md 用 @ 引用所有 rule，AI 自动加载。接口层（api-response 统一响应模型 / service-dao 接口实现分离）/ 质量层（error-handling 异常处理 / logging 日志 / testing 测试规范）/ 数据层（database 表设计 / batch 批量代替循环）/ 并发层（async 线程池 / distributed-lock 分布式锁）/ 工程层（git-branch 分支命名 / naming 命名规范）。安装：Mac Linux 用 cp -r，Windows 用 xcopy，或直接拖文件夹；装完在 CLAUDE.md 用 @ 引用 rule，下次干活就按你的规范来。
