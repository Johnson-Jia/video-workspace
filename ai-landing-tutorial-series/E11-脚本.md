## 脚本

### 开场（复用 tutorial-opening，~20s）

### hook（~30s，实操）
**旁白**：四个核心 skill，十三条团队规范，整个复制到自己项目就能跑。skill 按需调用，rule 始终生效，AI 自动遵守。这集讲 Skill 仓库实操——把 E09 的七种范式落地成一组拿来即用的资产，整个仓库开源，你拿去改改就能用。

> 视觉：深蓝底 + 大字「4 skill + 13 规范」+ 「复制即用」+ .claude/ 目录树生长。fx-aura 静态光晕。

### intro（~30s，方法论）
**旁白**：这集讲 Skill 仓库实操。前集讲了度量实操，这集换到沉淀复用的实操——怎么把团队的高频操作做成 skill，把规范做成 rule，统一放在 dot claude 目录。你能学到：skill 和 rule 怎么分工，三件套结构怎么组织，四个核心 skill 怎么用，十三条规范怎么分层，最后怎么装到你的项目。

> 视觉：三件套预告（SKILL.md / reference / rules）data-reveal stagger。

### 段1 Skill vs Rule（~50s，对比卡）
**旁白**：先说清楚 skill 和 rule 的区别。skill 是可复用的工作流加领域知识，AI 按需调用——你让它做某件事，它加载对应 skill。rule 是始终生效的规范，AI 自动遵守——不用你提，它每次都按规范来。一个按需，一个始终。比如 sql-query 是 skill，你让它查数据时调用；database 规范是 rule，每次写 SQL 自动按规范。两者配合，AI 既会干活又守规矩。

> 视觉：双卡对比（skill 按需调用 ⚡ / rule 始终生效 🛡）+ 例子（sql-query skill / database rule）。

### 段2 三件套结构（~55s，结构图，核心段）
**旁白**：一个 skill 的三件套结构。入口是 SKILL.md，声明这个 skill 干什么、怎么触发、调用什么。第二层是 reference 或 scripts，按需加载的详细资料和脚本，SKILL.md 只放骨架，细节放这里，AI 用到才读，省上下文。第三层是 rules 覆盖，可选，用来改写底层 skill 的默认行为，适配你团队的规矩。三件套让 skill 自包含、可复用、不臃肿。

> 视觉：三件套结构图（SKILL.md 入口 → reference/scripts 按需 → rules 覆盖）+ 每层一句话。

### 段3 4 核心 skill（~70s，四卡片，核心段）
**旁白**：仓库里有七个 skill，这集挑四个核心讲。其一，devflow，编排型，把需求到交付串成六阶段流水线。其二，sql-query，工具型，PostgreSQL 只读查询，三模式加安全护栏。其三，crud-gen，工具型，读表结构自动生成增删改查代码。其四，code-review，编排型，AI 代码审查加三级分级。四个覆盖了编排、工具、审查三类，团队最常用的高频操作基本都顾到。

> 视觉：四卡片网格（devflow 编排 / sql-query 工具 / crud-gen 工具 / code-review 编排）+ 每卡类型 + 一句话。

### 段4 devflow 编排型（~60s，流程图，核心段）
**旁白**：devflow 是编排型 skill，自己不实现，把多个 skill 串成流水线。它把需求到交付分成六阶段：探索、规范、计划、测试驱动、验证、归档。每个阶段调用对应工具——规范阶段调 OpenSpec，计划阶段调 Superpowers。它支持断点续传，中断了接着跑；支持规则覆盖，团队规矩能改写默认出口。devflow 把规范驱动开发从口号变成团队默认工作流。

> 视觉：六阶段流水线（探索→规范→计划→TDD→验证→归档）+ 每阶段调用的 skill（OpenSpec/Superpowers）+ 断点续传/规则覆盖 标签。

### 段5 sql-query + crud-gen（~55s，终端演示，核心段）
**旁白**：两个工具型 skill。sql-query 是 PostgreSQL 只读查询，三种模式覆盖不同场景，带安全护栏——只允许 SELECT，走 SSH 隧道，强制租户隔离，绝不乱写数据。crud-gen 是代码脚手架，读数据库表结构，自动生成分层的增删改查代码，从 domain 到 controller 一套，字段到操作符的映射也内置。两个都是高频工具，开发每天用。

> 视觉：terminal（sql-query 三模式 + 护栏 / crud-gen 读表→分层生成）+ scan_line 扫输出。

### 段6 code-review（~50s，卡片，核心段）
**旁白**：code-review 是编排型审查 skill。它按红黄绿三级分级，红色必须改，黄色建议改，绿色通过。关键在它自动核对下方 rule 规范——写 SQL 有没有按 database 规范，异常处理有没有按 error-handling 规范，不用人对照检查清单，AI 自动套规范。最后输出结构化报告，哪行违反哪条，清清楚楚。

> 视觉：三级分级卡（🔴红/🟡黄/🟢绿）+ rule 核对流向（database/error-handling → 自动套）+ 报告示例。

### 段7 团队规范 13 rule（~55s，分类卡）
**旁白**：十三条团队规范按职能分五层。入口是 team-conventions 总纲，CLAUDE.md 用 at 符号引用所有 rule，AI 自动加载。分层与接口层，api-response 统一响应模型，service-dao 接口实现分离。质量稳定层，error-handling 异常处理，logging 日志，testing 测试规范。数据层，database 表设计，batch 批量代替循环。并发层，async 线程池，distributed-lock 分布式锁。工程规范层，git-branch 分支命名，naming 命名规范。五层覆盖团队开发全流程。

> 视觉：五层分类卡（接口/质量/数据/并发/工程）+ 每层 rule 列表 + team-conventions 总纲入口。

### 段8 安装实操（~45s，终端演示）
**旁白**：装到自己项目很简单。Mac Linux 用 cp 命令，把需要的 skill 复制到项目的 dot claude skills 目录，把 rule 复制到 dot claude rules 目录。Windows 用 xcopy 或 copy，命令对应。不想敲命令就直接用资源管理器拖文件夹，效果一样。装完在项目根的 CLAUDE.md 里用 at 符号引用 rule，AI 自动加载，下次干活就按你的规范来。

> 视觉：terminal（cp -r skills/devflow .claude/skills/ + cp rules/*.md .claude/rules/）+ CLAUDE.md @ 引用。

**[终端演示 reveal]**
```
cp -r skills/devflow       your-project/.claude/skills/
cp rules/team-conventions.md your-project/.claude/rules/
# 项目根 CLAUDE.md 里 @ 引用
@.claude/rules/team-conventions.md
```

## 制作提示（继承 E01-E10 全部教训）

| 项 | 规则 |
|----|------|
| **双版本输出** | 版本1 `E11-final.mp4`（各段 output.mp4 concat）/ 版本2 `E11-final-pierce.mp4`（output_no_bgm concat + BGM 一首贯穿 volume 0.35 + bass 滤波 + bypass Mastering）|
| **BGM** | monochrome 系列（跨期去重避 E07-E10 pastel-soft/chill-lofi/warm-editorial/clean-corporate）|
| **⛔ 横屏** | design.md 显式 `orientation: landscape` + `resolution: 1920x1080`（s6_assemble 只读 design.md，缺字段默认 portrait）|
| **⛔ TTS +0%** | `tts_pipeline.sh` 显式传 `"+0%"` 第3位置参数（默认 +25% 不读 tutorial.md）|
| **⛔ 单 tut-scene** | 每段单 `.phase tut-scene` 内多 `tut-region` data-reveal stagger，**禁多 tut-scene static 平铺** |
| **⛔ .phase.tut-scene flex-start** | 内容从顶排列（避居中溢出底部条裁切），padding-top 188（过 safe_area gate content_y≥180），.region flex-shrink:0（不压缩）|
| **⛔ terminal 全显** | terminal region 全 `data-reveal=0`（不依赖 stagger 时序，t=0 全显）；内容精简（行数控制，避免溢出安全区）|
| **⛔ 渐变文字** | 两端都亮色高饱和（禁暗端 #B8842B/#1E6FB8/#DC2626 等，用 #FBBF24/#FCD34D/#60A5FA/#93C5FD/#34D399）|
| **⛔ text-shadow** | alpha ≤0.32（禁 0.6 浓阴影；0.08-0.32 极淡 drop）|
| **多音字** | 转→转型 / 藏→隐藏 / 9→九 / 校→检查 / 数→统计 |
| **禁"第一"** | 用"其一/首"（narration 避 no_forbidden_speech 子串误报）|
| **创作指令禁泄露** | narration/creative 禁"不录屏/真操作/信息节制" |
| **stagger 紧凑** | data-reveal 0/2/6/12 |
| **bg 强制组件** | components/bg/ 选 1 + 保留 `<!-- bg-component: NAME -->` 标记 |
| **fx 禁划过类** | 用 fx-aura/pulse/particle 静态类 |
