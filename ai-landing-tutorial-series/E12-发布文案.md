### 简介

E11 讲了 Skill 仓库（4 skill + 13 规范复制即用），这集进入汇报材料——把转型成果变成向上汇报的原生可编辑 PPT 和报告。

**核心**：5 类汇报 prompt 包加 ppt-master，30 秒出一份战略汇报 PPT，还是原生可编辑（DrawingML 结构，每个文本框都能改，不是图片式整张图）。

**你将学到**
- 四步工作流：准备数据 → 复制 prompt → 发 AI → 渲染
- 五类汇报模板（覆盖转型全周期）：战略汇报 PPT（PPTX）/ 转型计划书 / 周报 / 阶段总结报告 / 效果度量报告

- 别用错阶段：启动版禁编造验证成果（翻倍这类数据归阶段五成果版）
- 5 分钟最小可走通：占位数据 + 免费 AI（Kimi / 通义千问）30 秒出活
- ppt-master 生成原生可编辑 PPT：DrawingML 结构 vs 图片式整张图，开源一万六千星，二十多套 deck 参考
- prompt 是资产：不绑定工具，可独立交付

### 补充评论（要点拆条，可分多条发）

1. 五类汇报模板对应转型全周期：战略 PPT 立项要资源 → 计划书审批 → 周报跟踪 → 总结结项 → 度量证明提效。从立项到结项每一步都有对应模板。

2. 战略汇报 PPT 分两个版本，别用错阶段。启动版（阶段 1）靠现状痛点 + 目标承诺 + 试点计划立论，别编造翻倍这种验证数据——还没跑出来写了自己不信。成果版（阶段 5）才用实测数据。先确认你处于哪个阶段再选版本。

3. ppt-master 生成原生可编辑 PPT 是关键。DrawingML 结构，每个形状 / 文本框 / 图表 / 动画都是独立可编辑元素，PowerPoint 里能改每个细节。不是图片式 PPT 整张图不能改。开源一万六千星。

4. 5 分钟最小可走通：手头没真实数据也能先跑通。占位数据填进去（交付周期 28 天想压到 21 天之类），粘到免费 AI（Kimi / 通义千问），30 秒出一份结构齐全的战略汇报。先跑通流程，再补真实数据。

5. prompt 是资产，不绑定工具。这五个 prompt 包可以独立交付，换 AI 工具照样用，不绑定 Claude / ChatGPT / GLM 任何一个。
