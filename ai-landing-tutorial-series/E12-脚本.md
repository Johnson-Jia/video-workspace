## 脚本

### 开场（复用 tutorial-opening，~20s）

### hook（~30s，实操）
**旁白**：五类汇报 prompt，加一个 ppt-master，AI 帮你三十秒生成一份战略汇报 PPT，还是原生可编辑的，每个文本框都能改。这集讲汇报材料 AI 生成——转型最大卖点是向上汇报要资源，你的成果得变成上级看得懂的 PPT 和报告，这套 prompt 包加渲染工具，三十秒出活。

> 视觉：深蓝底 + 大字「5 类汇报 prompt」+「ppt-master 原生 PPT」+ PPT 页生长。fx-aura 静态光晕。

### intro（~30s，方法论）
**旁白**：这集讲汇报材料实操。前集讲了 Skill 仓库，这集换到汇报材料——怎么用五个 prompt 包加 ppt-master，把转型成果变成向上汇报的材料。你能学到：四步工作流、五类模板怎么选、战略汇报 PPT 的两个版本、五分钟最小可走通、ppt-master 怎么生成原生可编辑 PPT。

> 视觉：四步工作流预告（准备数据/复制prompt/发AI/渲染）data-reveal stagger。

### 段1 4步工作流（~55s，流程图，核心段）
**旁白**：汇报材料生成四步。开头，准备数据，整理你的真实数据，产出、AI 占比、Bug、进展这些。接着，复制 prompt，打开对应模板，复制 prompt 填进数据。然后，发给 AI，任意 AI 都行，Claude、ChatGPT、GLM 随便选，生成 Markdown 格式的汇报内容。最后，渲染，PPT 类用 ppt-master 生成原生可编辑 PPTX，文档类直接用或转 PDF。四步走完，一份完整汇报出炉。

> 视觉：四步流程图（准备数据→复制prompt→发AI→渲染）+ 每步图标 + 一句话。

### 段2 5类模板（~60s，五卡片，核心段）
**旁白**：五类汇报模板覆盖转型全周期。其一，战略汇报 PPT，向上汇报争取资源，输出可编辑 PPTX。其二，转型计划书，立项审批用，文档。其三，周报，关键节点跟踪，文档。其四，阶段总结报告，结项或晋升述职，文档。其五，效果度量报告，数据证明提效，能接 ai-metrics 的实测数据，文档。从立项到结项，转型每一步都有对应模板。

> 视觉：五卡片网格（战略PPT/计划书/周报/总结/度量）+ 每卡用途 + 输出格式标签。

### 段3 战略汇报PPT两版本（~70s，对比卡，核心段）
**旁白**：战略汇报 PPT 是核心，分两个版本，对应转型的两个阶段。启动版，阶段一立项要资源，还没试点、没有验证成果数据，靠现状痛点加目标承诺加行业参考加试点计划来立论。成果版，阶段五推广汇报，已经试点完了有实测数据，靠实测成果加推广计划来立论。同一份 PPT，两个阶段用不同的数据立论，关键是先确认你处于哪个阶段，再选版本。

> 视觉：双卡对比（启动版 阶段1 现状+目标+试点 / 成果版 阶段5 实测+推广）+ 阶段标注。

### 段4 别用错阶段（~50s，警示，核心段）
**旁白**：关键提醒，别用错阶段的数据。启动版绝对不要写人均产出翻倍、AI 占比七成这种验证成果——你还没跑出来，写了自己不信，一追问就穿帮。翻倍这类数据是阶段五用度量工具跑出来的结果，归成果版。启动版靠现状有多痛、目标要达到、先试点验证再说来支撑立项，更诚实也更有力。

> 视觉：alert_border 警示（⛔ 启动版禁编造验证数据）+ 对比（启动版：现状+目标 / 成果版：+104% 实测）。

### 段5 5分钟最小可走通（~55s，终端演示，核心段）
**旁白**：手头没有真实度量数据也能先跑通。打开战略汇报模板，填占位数据，随便编两个数就行，交付周期二十八天想压到二十一天，Bug 率百分之二十二。粘到免费 AI，Kimi 或通义千问都行。三十秒出活，AI 直接吐一份结构齐全的战略汇报，背景、目标、现状、行动、预期收益全有。先跑通一遍，确认流程没问题，再去补真实数据。

> 视觉：terminal（打开模板→填占位数据 28天/22%→粘免费AI→30秒出 Markdown）+ scan_line 扫输出。

**[终端演示 reveal]**
```
打开 01-战略汇报PPT.prompt.md
填占位：交付周期 28天 / Bug率 22%
粘到 Kimi 或 通义千问（免费）
→ 30秒出 Markdown 战略汇报
```

### 段6 ppt-master 原生 PPT（~60s，对比，核心段）
**旁白**：PPT 类汇报用 ppt-master 生成原生可编辑 PPT。关键是，ppt-master 生成原生 DrawingML 结构，不是图片式 PPT。每个形状、文本框、图表、动画都是独立可编辑元素，PowerPoint 里能改每一个细节。工作流是：AI 生成 Markdown 内容，在 Claude Code 里用 ppt-master skill，对它说用这份汇报内容生成 PPT，AI 按工作流生成原生可编辑 PPTX。开源一万六千星，二十多套精美 deck 能参考。

> 视觉：对比（图片式 PPT 整张图不能改 ❌ / ppt-master DrawingML 每元素可编辑 ✓）+ 工作流（Markdown→ppt-master→PPTX）。

### 段7 其他 4 模板（~50s，卡片）
**旁白**：其他四个模板快速带过。转型计划书，立项审批用，结构化论证为什么要转型、投多少、回本周期。周报，关键节点跟踪，每周进展、风险、下一步。阶段总结报告，结项或晋升述职，全周期回顾加成果加经验沉淀。效果度量报告，数据证明提效，能直接接 ai-metrics 的实测数据，相关性不是因果这句话必须标。四个文档类模板，覆盖转型各节点。

> 视觉：四卡片（计划书/周报/总结/度量）+ 每卡用途 + 输出格式。

### 段8 prompt 是资产（~45s，方法论）
**旁白**：为什么是 prompt 包不是工具。其一，用任意 AI，不绑定 Claude Code 或特定工具，ChatGPT、Claude、GLM 都行。其二，prompt 是内容资产，可单独交付、可独立卖，工具是可选渲染层，能替换。其三，可复制，拿 prompt 加自己数据，照做即生成，不靠灵感。整个目录自包含，五个 prompt 加一份说明，可独立打包分发或售卖。

> 视觉：三特点卡（任意 AI / 内容资产 / 可复制）+ prompt 包独立交付标签。

### CTA（~25s）
**旁白**：汇报材料是转型的对外发声，把成果变成上级看得懂的 PPT 和报告。下集讲 AI 自动化测试实操，跑 ai-test-frame，录制转生成加软断言。合集还有一集，点关注不走丢，教程仓库在评论区。最后问你：你的转型成果，向上汇报用什么形式？

> 视觉：合集标识 + E13 预告卡（测试实操）+ 关注 CTA + 中性提问。

## 制作提示（继承 E01-E11 全部教训）

| 项 | 规则 |
|----|------|
| **双版本输出** | 版本1 `E12-final.mp4`（各段 output.mp4 concat）/ 版本2 `E12-final-pierce.mp4`（output_no_bgm concat + BGM 一首贯穿 volume 0.35 + bass 滤波 + bypass Mastering）|
| **BGM** | warm-editorial 系列（跨期去重避 E07-E11：pastel-soft/chill-lofi/clean-corporate/monochrome）|
| **⛔ 横屏** | design.md 显式 `orientation: landscape` + `resolution: 1920x1080`（裸行，禁 markdown 列表 [[feedback-design-orientation-bare-line]]）|
| **⛔ TTS +0%** | `tts_pipeline.sh` 显式传 `"+0%"` 第3位置参数（默认 +25% 不读 tutorial.md [[feedback-tts-pipeline-default-rate]]）|
| **⛔ 单 tut-scene** | 每段单 `.phase tut-scene` 内多 `tut-region` data-reveal stagger，**禁多 tut-scene static 平铺** [[feedback-tutorial-single-tut-scene]] |
| **⛔ .phase.tut-scene flex-start** | 内容从顶排列（避居中溢出），padding-top 188，.region flex-shrink:0 |
| **⛔ terminal 全显** | terminal region 全 `data-reveal=0`；内容精简（行数控制避溢出）|
| **⛔ 渐变文字** | 两端亮色高饱和（禁暗端/白端点）+ text-shadow alpha≤0.32 + 禁胶囊 grad-* clip:text [[feedback-bgclip-text-capsule-conflict]] |
| **⛔ scene align-items center** | 横屏 scene align-items:center（禁 stretch 致 max-width 卡片偏左 [[feedback-tutorial-scene-align-maxwidth]]）|
| **⛔ mech-row 居中** | 多卡行加 justify-content:center（禁默认 flex-start 偏左）|
| **多音字** | 转→转型 / 藏→隐藏 / 校→检查 / 数→统计 / 调→调用 / 涨→涨星（已配 zhǎng）|
| **禁"第一"** | 用"其一/首"（narration 避 no_forbidden_speech 子串误报）|
| **禁"一定"** | 「不一定」→「未必」|
| **创作指令禁泄露** | narration/creative 禁"不录屏/真操作/信息节制" [[feedback-no-meta-instruction-in-content]] |
| **stagger 紧凑** | data-reveal 0/2/6/12 |
| **bg 强制组件** | components/bg/ 选 1 + 保留 `<!-- bg-component: NAME -->` 标记 |
| **fx 禁划过类** | 用 fx-aura/pulse/particle 静态类（禁 scan/stream/beam 划过）|
| **数字必须真实** | 28天/22%/三十秒/一万六千星 来自 README + 01 prompt，不编 |
