阶段5 · 度量算法
AI 战略转型方法论 · 20/30

三层识别,防伪造

自研 Go 工具,通过 Git 提交元数据识别 AI 代码——最可靠信号 + 风格学第二道防线 + 注册表
最可靠信号是 Co-authored-by trailer(AI 工具默认埋点),再加风格学第二道防线防伪造——应对 VS Code Copilot 误标 bug。
第 1 层
Co-authored-by 检测
解析 commit message 的 trailer,按工具名优先级匹配(claude/copilot/cursor/chatgpt/codeium/gemini),命中即置信度 1.0
→ AI 工具默认埋点,最可靠
第 2 层
风格学反伪造
作者历史 n-gram TF-IDF 余弦相似度复核:越像本人手写 → AI 署名可信度越低(1.0 - s,下限 0.1)
→ 防 VS Code Copilot 误标
第 3 层
双口径统计
提交占比 + 行数占比(后者更真实);支持按作者/模块/周下钻趋势
→ 四维度:code/quality/cost/agent
事前估算:AI 占比 =(AI 生成核心 + AI 辅助优化)÷ 总代码量。简单 CRUD ~90% / 复杂业务 ~70% / 平均约 75%
事后统计:git 元数据真实占比(实测 76.6%,落在估算区间内)——估算给方向,统计给真相
