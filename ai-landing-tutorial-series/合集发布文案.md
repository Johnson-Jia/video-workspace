## 二、合集描述（B 站简介）

80 人研发团队，3 个月，人均代码产出 +104%，AI 代码占比 76.6%，Bug 率下降 16.4 个百分点——怎么做到的？

这不是又一个 AI 工具测评，是一套经过真实团队实战验证的**企业级 AI 战略转型方法论**。7 个阶段（思想转变→战略→赋能→设施→试点→度量→沉淀），12 集深度解析，每一步都带着可运行的 demo 和真实数据，从战略规划到一线落地一份到底。

**你将学到**
- 思想转变：避开抗拒与盲目两个极端，拥抱 + 验证的正确姿态
- AI 原理速通：5 条原理让你精准下指令（token 预测 / 上下文 / Agent / REACT / 精准指令）
- 战略启动：向老板要预算的 ROI 公式 + 老板三问 + 失败预案
- 全员赋能：Claude Code + CLAUDE.md 规范资产化 + 五件套辨析
- 闭环试点：OpenSpec + Superpowers 一条命令跑通"需求到交付"
- 推广度量：AI 代码占比三层识别算法（Co-authored-by + 风格学 + 注册表，防伪造）
- 沉淀复用：7 种 Skill 范式，把个体经验变成组织资产

**适合谁看**
技术负责人 / 研发 Leader（主导转型）、想转型的开发 / 测试 / 组长 / 产品、企业决策者

**数据诚信**
+104% 等数据是转型前后对比观察，**相关性非因果**——不能 100% 归功 AI（需求变化、人员调整同期也在发生），但量级足以说明强相关。每个团队基线不同，别误读成"上了 AI 就涨 104%"。这套方法论从头到尾守这个底线：数据真、口径清、不吹。

**更新节奏**
每周 1 集深度解析，共 12 集，约 3 个月。合集点关注不走丢。

**教程仓库**
Johnson-Jia/ai-landing-tutorial —— 所有 demo 都能 clone 即跑：ai-metrics（度量）/ ai-test-frame（测试）/ report-templates（汇报 PPT）/ claude-skills（4 skill + 12 规范），拿来就用。

作者：Johnson，技术总监 / 首席架构师，80+ 人研发团队一线实战。
