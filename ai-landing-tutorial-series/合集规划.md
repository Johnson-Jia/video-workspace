# AI 战略转型方法论 · B站视频合集规划

> 基于教程 `D:/AI-Agent/ai-landing-tutorial` 的视频化推广。**每周 1 篇深度解析，10 分钟以上**，专业级企业解决方案定位。

## 一、合集定位

| 项 | 内容 |
|---|---|
| **合集名** | AI 提效转型实战：带研发团队从 0 到人均产出翻倍 |
| **一句话** | 80 人研发团队 3 个月人均产出 +104% 的全过程，拆成 13 集手把手教 |
| **受众** | 技术负责人 / 研发 Leader（主导转型）、想转型的开发/测试/组长/产品、企业决策者 |

## 三、每集脚本大纲（核心结构，10min+ 版）

每集统一结构（保证完播 + 专业感）：

```
0:00-0:30  钩子（痛点/数据/反常识，30 秒抓人）
0:30-1:00  这集讲什么（一句话 + 你能学到什么）
1:00-8:00  主体（拆解 + 屏录实操 + 动画讲解）
8:00-9:30  真实案例 / 数据证明
9:30-10:00 CTA（下集预告 + 合集引导 + 互动）
```

### E01 详细大纲（总纲，置顶，最重要）

- **钩子（0-30s）**：一个 80 人研发团队，3 个月，人均代码产出 +104%，AI 代码占比 76.6%，Bug 还降了——怎么做到的？
- **这集讲什么（30-60s）**：这不是又一个 AI 工具测评。这是一套**企业级 AI 战略转型方法论**，7 个阶段，从思想转变到全员提效，每一步都能落地，配套 5 个 demo 与资产包（2 个可直接运行 + 3 个拿来即用的资产）。
- **主体（1-8min）**：
  - 为什么必须转（AI 是生产关系重写，不转即落后）
  - 7 阶段全景图（总纲→战略→赋能→设施→试点→度量→沉淀）
  - 每阶段一句话 + 产出物
  - 5 个 demo 速览（可运行：ai-test-frame / ai-metrics；资产包：report-templates / role-handbooks / claude-skills）
- **数据证明（8-9:30）**：+104%/76.6%/-16.4pp 怎么来的（ai-metrics 度量；说明：转型前后对比，不能 100% 都算 AI 的功劳，需求 / 人员变动也有影响）
- **CTA（9:30-10min）**：下集讲思想转变（"为什么第一步不是上工具"）；合集已建，关注不走丢；评论区聊：你的团队开始用 AI 了吗？

### E02-E13 大纲（每集 2-3 句）

- **E02 思想转变**：两个极端要避免（抗拒 AI / 盲目崇拜）；5 条 AI 原理速通（token 预测/上下文/Agent/REACT/精准指令）；"人是根本"
- **E03 战略启动**：目标量化（10-20%→+50%）；预算 ROI（4 块成本 + 回本公式）；老板三问；失败预案（止损/回退）
- **E04 全员赋能**：Claude Code 安装前置（网络/中转）；CLAUDE.md 规范资产化；五件套辨析；推进治理（周会+强制周报）
- **E05 基础设施**：代码图谱（impact/detect_changes）；RAG；Skill 仓库；"小团队可跳过" + 降级方案
- **E06 闭环试点（核心）**：OpenSpec（WHAT/WHY）+ Superpowers（HOW）六阶段；devflow 编排型 skill；断点续传
- **E07 测试 + 案例**：防 AI 偷改测试三层防护；真实案例（form 编辑器 / 12 Controller 重构 / 前端 AI 陪练）
- **E08 推广度量**：多 Agent 并行；AI 代码占比度量（三层识别：Co-authored-by + 风格学 + 注册表）
- **E09 沉淀复用**：7 种 Skill 范式；知识沉淀；自我改进循环（AI 犯错→更新 CLAUDE.md）
- **E10 度量实操**：跑 demos/ai-metrics，实机演示三层识别 + Excel 模板 + HTML 报告
- **E11 Skill 仓库实操**：4 skill（devflow/sql-query/crud-gen/code-review）+ 13 规范 rule，复制到 .claude/ 即用
- **E12 汇报材料**：5 类汇报 prompt 包 + ppt-master 生成原生可编辑 PPT（5 风格展示）
- **E13 测试实操**：跑 demos/ai-test-frame，实机演示"录制 + AI 生成"范式 + 数据驱动 + 注册中心 + 软断言

### 配套资产口头点名（非单独成集，相关集带一句 + 置顶评论放链接）
- **术语表 / 技术栈 / 源码索引**（pages/appendix.html）→ E01 总纲带"术语速查"，各集用到时带出
- **4 份角色手册**（demos/role-handbooks/：开发 / 测试 / 组长 / 产品）→ E04 全员赋能点名"各角色手册已备好"
- **协调交接模板**（demos/handover-templates/：开发↔测试 / 前后端 / 跨部门）→ E06 闭环、E07 测试带出
- **验收审查清单**（demos/review-checklists/：落地验收 + 代码审查 checklist）→ E06 / E07 试点验收带出

## 四、创作方式（横屏 + 混合）

**教程类视频不适合纯 ClipForge 自动生成**（带代码实操要屏幕录制）。混合方式：

| 内容 | 工具 | 说明 |
|---|---|---|
| **代码 / 终端 / demo 实操** | 屏幕录制（OBS，1920×1080） | 教程核心——观众要看到真跑 |
| **方法论 / 流程动画 / 数据可视化** | ClipForge（tutorial 分类，横屏） | 片头、阶段流程图、数据飞升动画、过渡 |
| **旁白** | 自己配（教程类自己配 > AI 配音） | 专业感 + 可信度 |
| **合成 / 精剪** | 剪映 / Premiere | 屏录 + ClipForge 片段 + 字幕 + 封面 |

**ClipForge 的角色**：生成片头动画 / 数据可视化 / 流程图 / 封面 / 过渡——不是整片自动。教程的"真跑给人看"靠屏录。

## 五、发布节奏

- **频率**：每周 1 篇（建议固定日，如周三或周五）
- **合集**：B站建合集"AI 提效转型实战"，E01 置顶
- **标签**：#AI转型 #程序员 #ClaudeCode #企业级 #研发提效（每集固定 + 集数专属）
- **封面**：统一模板（暗色科技 + 集数 + 钩子文案 + 真实数据）
- **互动**：每集结尾 1 个二选一问题（非对抗式），评论区置顶放教程 GitHub 链接

## 六、落地路径

1. **先做 E01（总纲）**——合集能不能立住看这条。脚本见 `E01-总纲-脚本.md`
