# AI 战略转型方法论教程 · 重构方案（SPEC）

> 日期：2026-06-29
> 目标：把企业级 AI 战略转型全过程，提炼成「可复制、可批量推广」的方法论教程。

## 1. 核心理念（贯穿全教程，置于总纲）
- AI 能提效、能大幅扩展人的能力边界，但 **AI 不是万能的**——最终依赖使用人的能力边界。
- 路径：**转变思想、拥抱 AI → 先懂 AI 概念与原理 → 才能顺畅交互、精准下达指令**。
- 人 + AI，**人是根本**。

## 2. 组织框架：混合（阶段时间线骨架 + 能力域 + 角色视角）
重组现有 13 章为 6 个转型阶段（对应飞书全过程）：
- **阶段0 总纲**：思想转变 + AI 原理认知（Agent/REACT/上下文窗口/原理）
- **阶段1 战略启动**：为什么转 / 目标量化 / 路线图 / 组织 / 风险（领导向）
- **阶段2 全员赋能**：工具选型(Claude Code/Codex) + 培训 + 规范资产化
- **阶段3 基础设施**：RAG / 代码图谱 / Skill仓库 / MCP网关（**含跳过前提**：小团队可跳过）
- **阶段4 流程闭环与试点**：OpenSpec + Superpowers 工作流 + 试点验证
- **阶段5 推广与度量**：多Agent并行 + 效果度量 + 各组推广
- **阶段6 沉淀复用**：Skill范式整合 + 知识沉淀 + 避坑 + 持续改进

## 3. 每章统一内容结构（结论先行 + 可落地）
1. **【核心结论】** 一句话方法论（领导 30 秒看懂）
2. **【为什么】** 痛点/背景
3. **【落地步骤】** 怎么做（执行者照做）+ 真实代码/配置
4. **【角色视角】** Leader 关注什么 / 开发者做什么 / PM 做什么
5. **【真实案例】** 飞书全过程实践（验证后数据）
6. **【常见坑】+【复制清单】** 可批量推广的 checklist
