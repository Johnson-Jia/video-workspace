## 二、核心功能

Project NOMAD 通过 Docker 容器编排，将 6 大功能打包到一台电脑上，安装后**完全断网运行**：

| 功能模块 | 底层技术 | 说明 |
|----------|---------|------|
| **离线维基百科** | Kiwix | 完整版 99.6GB，含医学参考、生存指南、电子书 |
| **本地 AI 聊天** | Ollama + Qdrant | 支持 RAG 语义搜索，可上传文档对话 |
| **离线地图** | ProtoMaps / OpenStreetMap | 可下载区域地图，完全本地导航 |
| **教育平台** | Kolibri | Khan Academy 全部课程，进度追踪，多用户 |
| **数据工具** | CyberChef | 加密/编码/分析，安全研究瑞士军刀 |
| **笔记系统** | FlatNotes | 本地 Markdown 笔记 |

### 技术栈

- 后端：AdonisJS (Node.js/TypeScript)
- 前端：React + Inertia.js + Vite
- 数据库：MySQL
- 缓存/队列：Redis
- 容器化：Docker (DooD 模式 — Docker-outside-of-Docker)
- AI：Ollama + Qdrant
- 安装：一行命令 (`curl ... | bash`)

### 硬件需求

| 配置 | 规格 |
|------|------|
| **最低** | 双核 2GHz + 4GB RAM + 5GB 存储 |
| **推荐** | RTX 3060 + 32GB RAM + 1TB SSD |
| **完整 AI** | 需 GPU 跑本地大模型 |

## 四、反直觉角度（视频钩子素材）

### 角度 1："不需要云端也能跑 AI" ⭐⭐⭐⭐⭐

大多数人认为 AI = 云端 = 联网。NOMAD 证明一台旧电脑就能跑本地大模型，完全断网。这个认知反差极具传播力。

**钩子文案候选**：
- "拔掉网线，你的电脑还能干嘛？"
- "断网之后，这台电脑还能用 AI 聊天、查维基百科、看地图"

### 角度 2："末日工具却比 SaaS 更精美" ⭐⭐⭐⭐

同类产品是 $150-700 的树莓派盒子塞满 PDF。NOMAD 是有完整 UI 的 Web 管理面板（Command Center），暗色主题，安装向导，系统基准测试排行榜。CyberNews 称之为 "apocalypse-ready software"，但它看起来一点也不"末日"。

### 角度 3："用互联网对抗互联网消失" ⭐⭐⭐

整个项目的哲学是"互联网随时可能消失"，但安装过程需要联网下载几十 GB 内容。这个悖论本身就是有趣的故事角度。

### 角度 4："别人做轻量，他偏做重型" ⭐⭐⭐

大多数离线生存工具追求最小化、树莓派即可运行。NOMAD 反其道：推荐 RTX 3060+、32GB RAM。创始人明确说"如果你想要轻量级的，去找 Internet in a Box"。

### 角度 5："装网络的 YouTuber 做了 GitHub 最热项目" ⭐⭐⭐⭐

Chris Sherwood 不是 AI 研究员，不是全栈开发者。他用一年多时间，和一个开发者一起，做出了 28K+ Stars 的项目。YCombinator 社区在讨论他。

## 九、中国地区适用性分析

### 安装阶段：网络障碍严重

| 需要访问的资源 | 问题 |
|---|---|
| `ghcr.io`（Docker 镜像） | 被墙，主程序镜像无法直接拉取 |
| `raw.githubusercontent.com`（安装脚本） | 被墙，一键安装命令无法执行 |
| Ollama 模型下载 | 模型文件数 GB，从境外下载极慢或失败 |
| Kiwix ZIM 内容包 | Wikipedia 等内容源在境外服务器 |
| NPM 依赖 | `npm ci` 安装时部分包可能被墙 |

**结论：** 需全程挂代理，或手动将镜像/资源提前下载后离线导入。安装体验大打折扣。

### 内容语言：全英文，无中文适配

- 离线 Wikipedia → 英文版（中文 ZIM 需手动获取）
- Khan Academy 课程 → 英文
- 医学参考、生存指南 → 英文
- 地图数据 → OpenStreetMap，中文标注不完善

### 硬件门槛

- 推荐 RTX 3060 + 32GB RAM + 250GB SSD，国内可获得但成本不低
- 不跑 AI 功能可降至 4GB RAM 最低配置，但失去核心价值

### 断网运行本身：在中国反而更有价值

一旦安装完成，离线运行的场景在国内非常契合——偏远地区、应急通信中断、隐私敏感环境、教育信息化等。

### 综合判断

| 场景 | 可行性 |
|------|--------|
| 有代理 + 英文无障碍 + 愿折腾 | 可以用，体验完整 |
| 想给国内普通用户直接用 | 不现实，安装门槛和内容语言都是障碍 |
| 借鉴架构做中文版离线知识库 | 非常值得参考，架构设计清晰可复用 |

### 视频内容建议

如果面向中国受众制作视频，建议从以下角度切入：
- **"发现海外宝藏项目"** 而非 "直接可用工具推荐"
- 强调架构思路（Docker 编排 + ZIM/PMTiles 离线格式 + Ollama 本地 AI）的可复用性
- 提及中国开发者可以基于此思路做中文内容适配
- 避免过度简化安装过程，防止观众实际尝试后产生差评
