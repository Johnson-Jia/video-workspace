## 2. 二次元语音 TTS / 语音克隆

### 🏆 GPT-SoVITS — 少样本语音克隆 TTS

| 字段 | 值 |
|------|-----|
| **仓库** | [RVC-Boss/GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) |
| **Stars** | 45,000+ |
| **最后 commit** | 2026 年持续更新 |
| **近 3 月活跃** | ✅ 极度活跃（已迭代至 v3/v4） |
| **许可证** | MIT |

**推荐理由：** 二次元/VTuber 社区最流行的语音克隆工具。仅需 **1 分钟**语音样本即可训练高质量 TTS 模型。支持中/英/日三语零样本/少样本克隆，v3/v4 版本大幅提升情感表现力。广泛用于动漫角色配音克隆、虚拟主播语音合成。

**二次元使用场景：**
- 动漫角色声音克隆（少量样本即可复刻角色音色）
- VTuber 语音合成
- 二创视频配音

## 3. VTuber / 虚拟主播技术

| 字段 | 值 |
|------|-----|

| **Stars** | 7,963 |
| **最后 commit** | 2026-05-15 |
| **Open Issues** | 121 |

**推荐理由：** 当前最活跃的 AI VTuber 开源项目。支持任意 LLM 后端（OpenAI/Claude/本地模型）+ Live2D 面部追踪 + 实时语音对话 + 视觉感知。跨平台本地运行，支持免提语音交互和语音打断。v2.0 重写正在规划中，架构升级。

**核心能力：**
- 实时语音对话 + 语音打断
- Live2D 模型面部追踪
- 视觉感知（摄像头输入）
- 支持任意 LLM 后端
- 本地化运行，无需云服务
