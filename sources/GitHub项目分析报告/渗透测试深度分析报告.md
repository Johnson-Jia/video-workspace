### 2.1 SQLMap — SQL 注入自动化检测工具

#### 真实性证据 (基于代码读取)

| 硬指标 | 实测数据 | 证据来源 |
|--------|----------|----------|
| 版本号 | 1.10.6.50 (dev) | `lib/core/settings.py` 第23行 |
| 版权跨度 | 2006-2026 (20年) | 所有.py文件头 + LICENSE文件 |
| 作者 | Bernardo Damele, Miroslav Stampar | LICENSE 第4行 |
| Python文件数 | 488个 | `find *.py \| wc -l` |
| 自有Python代码 | 58,261行 | 排除thirdparty目录 |
| 最近commit | 2026-06-05 | git log (浅克隆) |
| DBMS插件 | 31种数据库 | `plugins/dbms/` 目录实际计数 |
| Tamper脚本 | 71个 | `tamper/` 目录实际计数 |
| 内嵌第三方库 | 19个 | `thirdparty/` 目录 |

**真实性结论: 确认真实。** 20年版权跨度、58,000+行自有代码、31种数据库插件、71个WAF绕过脚本，是高度成熟的工业级工具。

#### 可用性评估

- **零外部依赖**: 所有19个第三方库以源码形式内嵌在 `thirdparty/` 目录，无 requirements.txt、无 pip install
- **Python 版本**: 2.7 或 3.x (含 bz2, gzip, ssl, sqlite3, zlib 扩展)
- **跨平台**: Windows/Linux/macOS 均支持，CI 测试覆盖三平台
- **体积**: 仅 12MB，无需安装
- **运行命令**: `python sqlmap.py -u "http://target/page?id=1" --batch`

#### 易用性评估

| 特性 | 评级 | 证据 |
|------|------|------|
| 初学者向导 `--wizard` | 优秀 | `lib/parse/cmdline.py` 定义 |
| GUI 模式 `--gui` | 可用 | Tkinter 实现 |
| 交互式 Shell `--shell` | 优秀 | 内置 REPL |
| 非交互模式 `--batch` | 优秀 | 适合自动化 |
| 配置文件 `sqlmap.conf` | 完善 | 22,881字节INI模板 |
| REST API | 可用 | `sqlmapapi.py` 118行 |
| 多语言文档 | 优秀 | README提供26种语言翻译 |

**学习曲线: 低-中**。基础使用仅需一条命令，高级功能(如tamper脚本组合)需要SQL注入知识。

#### 使用限制

1. **GPLv2 许可证**: 衍生作品定义严格，商业集成需联系 sales@sqlmap.org 获取商业许可
2. **法律免责**: 每次启动显示法律警告，仅限授权测试
3. **功能边界**: 仅针对SQL注入漏洞，不支持XSS、CSRF等其他漏洞类型
4. **高级功能**: OS接管功能需要额外安装Metasploit

#### 代码质量

- **模块化程度: 极高** — 31种DBMS插件独立组织，71个tamper脚本独立文件，注入payload以XML声明式定义
- **CI/CD**: GitHub Actions，跨3个OS × 3个Python版本测试
- **内置测试**: `--smoke` 冒烟测试 + `--vuln` 漏洞测试
- **异常处理**: 针对约30种已知错误场景提供友好提示

#### 可用性评估

- **Ruby 版本**: >= 3.1 (推荐 3.3.8)
- **运行时依赖**: 约 120+ gems (含 PostgreSQL pg gem、nokogiri、ffi 等需编译的native扩展)
- **数据库**: PostgreSQL (高级功能需要)
- **安装难度**: 高。推荐使用 Kali Linux 预装版或官方安装器
- **Windows 支持**: 有限，部分功能需要额外配置

| 入口工具 | 功能 | 成熟度 |
|----------|------|--------|
| `msfconsole` | 主交互式控制台 | 核心，高度成熟 |
| `msfvenom` | 独立payload生成器 | 高度成熟 |
| `msfdb` | 数据库管理 | 成熟 |
| `msfrpc/msfrpcd` | RPC接口 | 成熟 |
| `msfmcpd` | MCP/AI集成接口 | 新功能 |
| `msf-ws.ru` | Web服务 | 可用 |

**学习曲线: 高**。需要网络安全基础知识，但社区文档极其丰富(GitHub Discussions, Slack, 官方文档站点 docs.metasploit.com)。

#### 使用限制

1. **BSD-3 许可证**: 相对宽松，允许商业使用，需保留版权声明
2. **第三方组件混合许可**: 部分模块使用 GPL-2.0、GPL-3.0、LGPL、MIT 等不同许可证
3. **环境要求高**: Ruby 3.1+、PostgreSQL、编译工具链(nokogiri, ffi等)
4. **体积大**: 281MB源码 + gem依赖

#### 代码质量

- **模块化程度: 优秀** — exploit/payload/encoder/auxiliary/post/evasion 各有独立基类
- **REX库**: 13个独立gem (Ruby Exploitation Library)，覆盖crypto/exploit/payloads/proto等
- **测试覆盖**: 573个RSpec测试文件，使用factory_bot_rails + simplecov
- **代码风格**: rubocop 1.75.7 强制检查
- **AI集成**: 已支持 MCP (Model Context Protocol)，可通过AI辅助交互

2. **LLM API 成本**: 每次运行约 $1.11，长期使用有成本
3. **AI 不确定性**: LLM 可能产生不准确建议，需人工判断
4. **自主模式**: 最强功能(autonomous mode)需要Claude Code CLI付费订阅

## 四、TOP 3 推荐

### 推荐第1名: SQLMap

**推荐理由 (全部基于代码证据):**

1. **零依赖即插即用**: 58,261行自有代码 + 19个内嵌第三方库，`python sqlmap.py` 即可运行，无需任何安装过程。在所有12个项目中，这是唯一一个真正做到"下载即用"的工具。
2. **20年持续维护**: 版权跨度2006-2026，最近commit 2026-06-05，版本1.10.6.50，说明项目仍在活跃迭代。
3. **覆盖面最广的SQL注入工具**: 31种DBMS插件、71个WAF绕过脚本、6种注入技术(boolean_blind, error_based, time_blind, union_query, stacked_queries, inline_query)。
4. **多层次的易用性设计**: `--wizard`(初学者向导)、`--gui`(图形界面)、`--shell`(交互式)、`--batch`(自动化)满足不同水平用户。
5. **代码质量极高**: 模块化设计、130+个CLI参数分组清晰、CI/CD跨平台测试、约30种异常场景友好处理。

**使用限制提醒:**
- GPLv2许可证，商业集成需获取商业许可
- 仅覆盖SQL注入漏洞类型
- 必须在合法授权目标上使用

---

### 推荐第2名: Metasploit Framework

**推荐理由 (全部基于代码证据):**

1. **最全面的渗透测试框架**: 4,992个模块(2,661个exploit + 1,319个auxiliary + 504个payload + 433个post + 其他)，覆盖20个操作系统/平台，是其他任何开源工具无法比拟的。
2. **工业级代码质量**: 8,254个Ruby文件、573个RSpec测试、13个独立REX gem库、ActiveRecord ORM、完善的插件系统(35个插件)。
3. **行业事实标准**: 由Rapid7维护，GitHub上85,000+ commits，持续到2026-06-08仍有PR合并。安全行业公认的渗透测试框架。
4. **BSD-3许可证**: 在所有项目中许可证最宽松之一，允许商业使用和修改。
5. **AI集成前瞻性**: 已支持MCP (Model Context Protocol)，可通过 `msfmcpd` 守护进程与AI交互。

**使用限制提醒:**
- 环境要求高: Ruby 3.1+、120+ gems、PostgreSQL、编译工具链
- 学习曲线陡峭，需要网络安全专业背景
- 安装过程复杂，推荐使用Kali Linux预装版
- 项目体积281MB，依赖链长

---

### 推荐第3名: PentestGPT

**推荐理由 (全部基于代码证据):**
